# 05. QA / 리스크 의견서 — 연(緣) / Yeon (Final V8 정식판 평가)

> 작성: QA·리스크 분석가(악마의 변호인) / 평가 기준일 2026-06-27 / 톤: 리스크 우선·최대 비판
> 평가 대상: Notion 「연(緣) — GDD Final V8」 (졸업작 946 CE 버티컬 슬라이스 + 본게임 1401 CE)

## 한 줄 결론
**문서 완성도는 높으나, "확정처럼 서술된 가정값"과 "1인 직렬 병목 + Plan B 전면 폐기"가 겹쳐 졸업작조차 일정·코어 동시 붕괴 위험을 안고 있다. 현 상태로는 GREEN이 아니라 조건부 진행(YELLOW)이며, 미해소 시 RED로 떨어진다.** 본게임은 사실상 미설계 상태로 평가 대상에서 제외해야 한다.

## 2. 영역별 리스크 상세

### 2.1 스코프 vs 1인 개발 (★ 최우선)
- 17.3 자체 추산: 애니메이션 총합 **45~72일**, 이무기만 32~52일을 Q3(약 90일) 단일 분기에 소화. 같은 분기에 보스 AI State Machine, VFX 통합, MetaSound 연결이 병렬. **산술적으로 "범위 안"이라 적었으나 버퍼 0, 직렬 1인, 학습/디버깅/재작업 시간 미반영** — 현실 부담은 1.5~2배로 봐야 한다.
- D-06으로 **이무기 Plan B 전면 폐기**. 최고 심각도 항목에 대안 라인이 없다는 것은 단일 실패점을 의도적으로 만든 것. "실패 시 2028 이월"은 곧 1차→최종 슬립이 졸업 일정을 직접 위협함을 자인.
- 본게임(6장, 22.3)은 챕터 수·보스 다수·잡몹·흑화·본모습·연 메커닉·여우구슬 메커닉 전부 "본게임 착수 시" 미결 → **본게임은 비전 선언일 뿐 설계가 아니다.** 평가/투자 판단에서 본게임 매출 시나리오(BM)는 근거 박약으로 취급.

### 2.2 "가정값" 위험 (★)
- 7.2가 백연 HP 1,000만 (확정), 나머지(이무기 HP, 전 데미지, 페이즈 길이, 보스전 4~7분)는 전부 2027 Q2~Q3 확정 예정인데 표 형식과 "수치 구조 설명"이 **확정 밸런스처럼 읽힌다.** 문서 신뢰성 함정: 외부 독자(교수·퍼블리셔)가 검증된 수치로 오인.
- 예고 타이밍(1P 0.8~1.0초 → 2P 0.55~0.7초), 입력 버퍼 0.08초("의도적 타이트")가 프로토 전 값. 플레이테스트에서 2P 0.55초가 "읽기 불가"로 판명되면 코어 루프(읽기→Dash→콤보)의 전제가 흔들리고, 거대 보스 Opacity 0.3 근접 카메라와 결합 시 가독성 동시 붕괴.
- HP 전체 리셋(부분 체크포인트 없음) + 단일 세션. Primary(소울 하드코어)에는 정직한 패널티지만, Secondary(아트·내러티브)와 심사위원 평균치에는 좌절 이탈 구조. **두 페르소나를 한 난이도로 잡겠다는 1.6의 전제 자체가 미검증 가정.**

### 2.3 단일 난이도·접근성 공백 (★)
- easy/normal/hard 없음, 접근성 토글(타이밍 보조·데미지 스케일·자동 락온 강도) 기획서에 없음. 18.2의 "난이도 배율 Float 1개 일괄 제어"는 내부 튜닝 수단이지 **플레이어 선택지가 아니다.**
- 졸업 심사·퍼블리셔 시연은 통제 불가 1회성. 평가자가 막히면 트레일러 인상까지 깎인다. **시연용 어시스트/디버그 스킵(컷신 ESC 스킵은 22.1 "미결")이 합격선에 직접 영향.**

### 2.4 콘텐츠/리플레이 (★)
- 4~7분 1보스·단일 엔딩·메타 진행 없음·외재 보상 없음. 19장의 "시스템 줄이고 연출 올린다"는 스코프 방어로는 옳으나, **포트폴리오 반복 시연 매력과 "분량" 인상에서 불리.** 트레일러(≤90초) 의존도가 과도하게 높아진다.

### 2.5 서사 전달
- 산군=시체 + "...산군." 한 마디로 관계 전달, 컷신·대사 최소. 신화 비숙지/해외 평가자에 백연(구미호=산신 역전), 여우구슬 vs 여의주, 연(緣) 테마가 전달 실패할 개연 높음. **환경 내러티브는 맥락 공유 관객에 강하고 콜드 평가자에 약하다.**
- 정적 엔딩(후퇴)과 "공간의 주인" 카타르시스 충돌(R7): 완전 처치가 아닌 "도망간 적"은 일부 플레이어에 미완 감각. 본게임 떡밥과 졸업작 단독 완결성이 트레이드오프.

### 2.6 시장/포지셔닝
- 3.3·1.5가 Black Myth: Wukong 매출(1B+/25M)을 시장 유효성 근거로 사용. **대작 매출은 1인 졸업작의 도달 가능성과 무관** — 기대치 인플레만 유발. "다음 동양 신화" 슬롯은 Wukong·Wo Long·Phantom Blade 등으로 포화. USP("구미호를 산신으로")는 유효하나, 시장 근거는 규모 일치하는 한국 인디 사례로 교체 필요.

### 2.7 고증/문화 + 섭외
- 구미호=산신, 이무기 여우구슬 탈취, 여의주 대체 재해석은 창작 자유 범위지만 신화 왜곡 논란 소지 낮게 존재. 사진참사검 명문 고증은 강점.
- **보이스 "레퍼런스 배두나/전도연"이 톤 지향인지 실제 섭외 가정인지 불명확.** 전투 보이스·결말 대사 모두 22.1 미결. 외부에 실섭외로 오인되면 신뢰 리스크. 문서에 "톤 레퍼런스, 섭외 아님" 명시 필요.

### 2.8 일정 단일 실패점
- 2.1·16.1: 복무 전역 2027.3 전제. 전역 지연/연장, 전역 후 번아웃·취업 병행 시 2027 Q2 착수 자체 붕괴. 전체 일정에 **복무 종료 불확정에 대한 버퍼·대안 트랙 없음.**

## 4. 검증 가설 (반증 가능한 형태로)

- **H1.** "2P 예고 0.55~0.7초 + 거대 보스 근접 카메라(Opacity 0.3)에서 평균 플레이어가 예고를 읽을 수 있다" → 프로토 1주차에 반증되면 R2·R3 동시 발화.
- **H2.** "HP 전체 리셋 단일 세션을 비숙련 평가자가 좌절 없이 완주한다" → 시연 이탈률로 측정. 반증 시 접근성 옵션 불가피.
- **H3.** "이무기 9종 애니 32~52일이 Q3 내 처리 가능하다" → Q2 종료 시점 진척률로 조기 판정(18.1 판단 시점과 일치).
- **H4.** "환경 내러티브만으로 신화 비숙지 평가자가 백연·연 테마를 인지한다" → 시연 후 구두 인터뷰로 검증.

## 7. 최종 판정

**조건부 진행 (YELLOW).** 졸업작 스코프 통제(Zone C 단일·시스템 축소·자유 혼용 콤보·폴리싱 우선순위)와 리스크 자가 인식은 1인 프로젝트 기준 상위권이다. 그러나 **(a) 최고 위험 항목(이무기)에 Plan B 부재, (b) 코어 수치 전반의 미검증, (c) 난이도/접근성 공백, (d) 복무 단일 실패점** 네 가지가 동시에 살아 있어 GREEN을 줄 수 없다.

- **즉시 조치(GREEN 전환 조건):** 접근성/시연 어시스트 결정 추가, 7.2 가정값 워터마크, 복무 버퍼 명시, 이무기 Q2 게이트 정의.
- **RED 전환 트리거:** 프로토 1주차에 H1(예고 읽기) 반증 / Q2 종료 시점 이무기 진척 50% 미만 / 전역 지연.
- **본게임 트랙:** 현재 평가·투자 근거로 사용 불가(전 구조 미결). 졸업작 산출물 단독 가치로만 심사받을 것.
