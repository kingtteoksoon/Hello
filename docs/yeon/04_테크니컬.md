# 04. 테크니컬 평가 의견서 — 연(緣)/Yeon (Final V8)

> 평가자: 테크니컬 디자이너(UE5) / 톤: 비판적·리스크 우선 / 초점: 1인 개발 실현 가능성
> 평가일: 2026-06-27 / 대상: 졸업작 보스전 버티컬 슬라이스(946 CE, 2027 Q4 1차)

## 한 줄 결론

**기술 스택 선택과 스코프 절제는 동급 1인 프로젝트 중 상위권으로 건전하다. 그러나 전체 일정이 "전역(2027.3) → 2027 Q2 착수 → 2027 Q4 1차"라는 약 2~3분기에 의존하며, 이 안에 이무기 에셋 직접 제작(45~72일 추정)·프레임 전투·보스 AI·VFX·사운드·트레일러를 직렬로 욱여넣는다. 일정은 거의 확실히 슬립한다. 기획서가 2028 이월을 자인한 것은 정직하지만, 그 자인은 사실상 "1차 마감은 목표가 아니라 희망"이라는 뜻이다.**

## 1. 기술 스택 적정성

- **UE5 / Blueprint+C++ 병행** — 합리적. 포트폴리오로 C++ 노출이 평가 대상이 된다는 판단(2026.05.07 결정)은 맞다. 다만 "BP로 검증 후 C++ 전환"은 1인 환경에서 **두 번 짓는 비용**을 의미한다. 피니시 절차적 카메라·State Machine 외에는 C++ 전환을 적극 자제할 것을 권고한다. C++ 전환은 디버깅 표면을 넓혀 1인 유지보수성을 떨어뜨린다.
- **보스 AI = State Machine (BT/StateTree 불사용)** — 졸업작 단일 보스·페이즈당 패턴 3종 규모에선 **정당**. BT의 블랙보드/데코레이터 오버헤드 없이 페이즈×패턴을 명시적으로 다루는 편이 디버깅이 쉽다. 단, 시선고정+회피후추격+예고분리를 FSM 전이로 엮으면 상태 폭발이 빠르다. **UE5.x StateTree**는 FSM의 가독성과 BT의 확장성 사이에 있어, 본게임 다보스 확장을 고려하면 졸업작부터 StateTree로 가는 편이 재작성 비용을 줄인다. 기획서의 "본게임 다보스 확장"과 "졸업작 순수 FSM"은 충돌 소지 — **G/D 대기열에 명시 권고.**
- **카메라 = SpringArm + 동적 거리추적 + 락온** — 표준적이고 안전. 락온 거리·스무싱 미결은 정상(프로토 후 확정). 24m 보스 + 50×50m 아레나에서 SpringArm 단독으로 보스 전신과 발밑 예고를 동시에 화면에 담는 것은 **난제**다. 동적 FOV/거리 보간 튜닝이 카메라 작업의 80%를 잡아먹을 것. Plan B(피니시 측면 고정컷)는 현실적 안전장치로 좋다.
- **VFX = Niagara** — 8종 리스트는 모두 Emissive/짧은 잔상/단발 폭발로, **Niagara 사양 기준 난도 낮음**. 1페이즈 청록(#006B6B) Emissive의 자연광 하 가시성 우려를 기획서가 스스로 잡은 것은 좋은 신호. 여우구슬은 연출 전용으로 게임플레이 영향 0 — 리스크 낮음.
- **오디오 = MetaSound + Suno 1차본** — 페이즈 크로스페이드/마디맞춤은 MetaSound로 적합. 5트랙 Suno 프롬프트 완료는 진척. 저위험.

**총평: 스택 자체는 위험 요인이 아니다. 위험은 전부 "양"과 "시간"에 있다.**

## 2. 1인 개발 병목 분석 (에셋 / 코드 / 일정)

### 2.1 에셋 — ★최대 병목 (기획서 자체 평가와 일치)

- 기획서의 직접 추정 **이무기 9종 32~52일 + 백연 직접 4종 8~12일 + 마켓 수정 5~8일 = 45~72일**. 여기에 **모델링·리깅 일수가 빠져 있다.** 17장은 애니메이션만 합산했고, 8.2는 모델·리깅을 "직접 제작"으로 명시하면서 일수를 추정조차 하지 않았다. 24m 뱀+용 하이폴리, 검은비늘 텍스처, 페이즈별 눈색/Emissive 머티리얼, **스파인 체인이 긴 뱀형 리그**(IK/스플라인 리깅은 휴머노이드와 별개 난도) — 보수적으로 **모델 10~20일 + 리깅 7~15일**을 더해야 한다. **실질 에셋 부담은 60~100일+**로 봐야 하며, 이는 Q3 90일을 단독으로 소진한다. 그런데 같은 Q3에 보스 AI·VFX·사운드 통합을 병행하라고 적혀 있다. **산술적으로 불가능에 가깝다.**
- **"애니메이션 AI 툴 보조"의 함정**: 현존 모션생성 AI는 휴머노이드 리타깃 중심이다. **비휴머노이드 거대 뱀**에 대한 AI 모션 보조는 사실상 작동하지 않거나 후처리(리타깃 정리)가 직접 제작과 맞먹는다. "AI 툴 보조"를 일수 절감 근거로 삼는 것은 낙관 편향. **추정을 AI 보조 없는 수동 기준으로 재산정할 것.**
- **마켓플레이스 현실**: 기획서도 인지하듯 "동양 신화 거대 뱀 보스" 기성 에셋은 사실상 부재. Fab의 서양 드래곤/와이번 리타깃은 비늘 결·뿔·체형이 안 맞아 결국 직접 제작으로 수렴. **Phase 1 프록시 → Phase 2 직접 제작 전환은 사실상 "프록시 폐기 후 전부 재작업"**이며, 프록시로 검증한 AI·카메라 파라미터가 본 모델 체형에서 다시 흔들린다.
- **Plan B 전면 폐기(D-06)는 가장 위험한 결정.** "안개 실루엣/유료 에셋/AI 모델링"을 정체성·신뢰성 이유로 전부 버리고, 실패 시 대응을 "2028 이월" 단일 카드로 둔 것은 **최대 리스크 항목에 안전장치가 0**이라는 뜻이다. 최소한 **부분 Plan B**(예: 본 모델 미완 시 졸업 제출은 회색 프록시+완성도 높은 라이팅/연출로 트레일러만 사수)를 살려둘 것을 강력 권고.

### 2.2 코드 — 프레임 전투 구현 (높음, 그러나 관리 가능)

- 캔슬윈도우(후딜 0~80%)·입력버퍼 0.08초·히트스톱 0.05~0.12·프레임 정확 히트박스는 **AnimNotify/NotifyState + 상태플래그**로 구현하는 표준 패턴이며 기술적 미지는 낮다. 진짜 비용은 **구현이 아니라 반복 튜닝**이다. 프레임값 1개 바꿀 때마다 빌드 PC에서 직접 플레이로 체감 확인 — **1인이므로 외부 테스터 없는 자가 튜닝 루프**가 길어진다.
- **권고: 모든 전투 프레임값을 DataTable/DataAsset로 외부화**하여 에디터에서 런타임 튜닝 가능하게 할 것. 하드코딩 시 Q3 튜닝이 재컴파일 지옥이 된다. 이건 프로토 1주차 전에 깔아야 하는 인프라다.
- 히트박스는 소켓 기반 콜리전 + NotifyState 토글로 충분. 프레임 단위 정밀도는 60fps 고정에서 1프레임=16.7ms이므로, 기획의 0.05초(3프레임) 단위 값은 **현실적으로 표현 가능**. 단 가변 프레임레이트에서 틱 기반 타이머는 오차 누적 — **틱이 아닌 애님 정규화 시간 기준**으로 윈도우를 잡을 것.

### 2.3 일정 — ★단일 실패점 (최고)

- **복무기간 미확정이 전체 일정의 단일 실패점.** 전역 2027.3 가정이 한 분기라도 밀리면 Q2 착수가 통째로 밀려 Q4 1차는 자동 붕괴. 기획서가 "복무 미확정"을 리스크로 자인했으나 **일정표는 확정인 양 짜여 있다** — 모순. **전역 +1분기 슬립 시나리오를 별도 일정안으로 명문화**할 것.
- "Q2 착수 → Q2 프로토 1주차 → Q3 제작·밸런스 → Q4 1차"는 **밸런스 확정을 외부 플레이테스트 없이 자가 1회로 끝낸다**고 가정. 소울라이크 보스 밸런스(Primary 페르소나의 공정성 요구)를 자가 1회로 잡는 것은 비현실적. **최소 3~5명 외부 테스트 라운드**가 Q3에 추가로 필요하며, 이는 일정에 미반영.

## 4. 컷 권고 · MVP 제안

- **메뉴·세이브·인벤토리·스킬트리·여우구슬 메커닉 컷은 전적으로 합리적.** 단일 세션 보스전에 맞다. 심사 환경 제약은 ESC 스킵·자동 페이드 종료로 충분히 커버되며 별도 메뉴 불필요.
- **추가 컷 권고 (1차 마감 사수용 MVP)**:
  1. **이무기 패턴을 1차 마감 한정 페이즈당 2종으로 선제 축소** (기획서 Plan B를 기본안으로 승격). 패턴 3종×2는 애니 부담의 직접 동인. 2종×2로 시작해 시간 남으면 추가.
  2. **2페이즈 강화돌진(1페 베이스 변형) 외의 신규 2페 모션을 최소화** — 색상·속도 변화로 차별을 주고 신규 모션은 꼬리휩쓸기 1종만 사수.
  3. **컷신 전량 절차적 카메라 1차안만** (Level Sequencer 2차는 시간 남을 때만 — 기획과 일치, 재확인).
  4. **C++ 전환을 피니시 카메라 1개 모듈로 한정**, 나머지는 BP 유지. 포트폴리오용 C++ 노출은 그 1개로 충분히 입증된다.
- **MVP 정의 제안 (2027 Q4 사수선)**: "이무기(완성 모델) × 2페이즈 × 패턴 2종 × 전투 4~5분 완주 + 절차적 피니시 1컷 + BGM/SFX 통합 + 90초 트레일러." 이 선을 깨면 트레일러부터 사수하고 빌드 완성도를 후순위로 — 졸업/퍼블리셔 미팅 자료의 80%는 트레일러가 한다.

## 5. 미결 지적 (테크니컬 관점 추가)

- **모델링·리깅 일수 추정 부재(8.2)** — 최대 리스크의 절반이 정량화되지 않았다. 프로토 전 반드시 산정.
- **"AI 툴 보조" 정의 미확정** — 어떤 툴이 비휴머노이드 뱀 리그에 작동하는지 검증 안 됨. 2027 Q2 착수 전 **PoC 1건**(서양 드래곤 무료 에셋에 AI 모션 보조 적용) 필수.
- **전투 프레임값 외부화 여부 미명시** — DataTable/DataAsset 채택을 인프라 결정으로 명문화.
- **State Machine vs StateTree 본게임 확장 정합성** — 결정 대기열 추가.
- **외부 플레이테스트 라운드 미편성** — 밸런스 확정(Q3)의 전제. 일정에 명시.
- **틱 기반 타이머 vs 애님 정규화 시간** — 가변 프레임레이트 오차 대비, 윈도우 기준 명시.
- **복무 +1분기 슬립 대체 일정안** — 단일 실패점에 대한 분기 시나리오 부재.

### 최종 판정

스택·스코프·문서화는 1인 졸업작으로서 **상위 건전성**. 그러나 **(1) 이무기 에셋의 모델·리깅 미산정 + Plan B 전면 폐기, (2) 복무 미확정이라는 단일 실패점, (3) Q3 단일 분기 직렬 충돌** — 이 셋이 동시에 살아 있는 한 2027 Q4 1차는 목표가 아니라 희망이다. **2028 이월을 기본 시나리오로 받아들이고, 트레일러를 진짜 1차 산출물로 재정의**하는 것이 가장 정직한 일정 운용이다.
