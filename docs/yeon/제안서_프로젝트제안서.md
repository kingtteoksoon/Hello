# 연(緣)/Yeon — 프로젝트 제안서

> **대상:** 「연(緣) — 게임 디자인 기획서 (Final / V8 정식판)」
> **작성:** 코드 에이전트 팀(총괄 + 6개 직군) · 2026-06-27
> **성격:** 평가 기반 실행 제안 — 비판적·리스크 우선, 건설적 방향 제시
> **범위:** 졸업작(946 CE 이무기 보스전 버티컬 슬라이스) 중심. 본게임(1401)은 전 구조 미결로 제안 대상에서 제외.

## 1. 프로젝트 비전 요약 (있는 그대로)

「연(緣)」은 **"구미호를 악역도 인간 지망생도 아닌 산신(山神)으로 플레이하는 한국 신화 3D 액션"**이다. 주인공 백연(백두산 산신)이 자신의 영역을 침범한 이무기를 검으로 처리한다. UE5·1인 개발·PC(Steam). 두 트랙으로 나뉜다: **졸업작**(946 CE, 이무기 첫 충돌 단일 보스전, 무료 배포 — 졸업 쇼케이스·포트폴리오·퍼블리셔 미팅·KOCCA 응모용)과 **완성작**(1401 CE, 지리산 결전, Steam 정식, 2029~ 추정).

코어 루프는 **읽기(보스 예고) → Dash 회피 → 약/강공 자유 혼용 콤보 → 피니시**이며, 노리는 단일 감정은 **"내가 이 공간의 주인"이라는 카타르시스**다.

## 2. 평가 기반 핵심 진단 — 두 개의 간극

본 팀(6개 직군)의 평가는 한 줄로 수렴한다: **이 기획은 1인 졸업작 기준 스코프 절제·문서 밀도가 상위권이나, 두 구조적 간극이 전체를 관통한다.**

1. **USP–산출물 간극:** "산신 구미호" USP는 본게임에 있는데, 실제 졸업작 산출물(단일 보스전)은 그것을 거의 증명하지 못한다. 졸업작 USP는 사실상 아트·연출·캐릭터에 전적으로 의존한다.
2. **가정–확정 간극:** 밸런스·타이밍·페이즈 길이·일정이 전부 "프로토 1주차 전 가정값"인데 4~7분·트레일러·2027 Q4 마감이 이를 확정 스펙처럼 전제한다.

→ 본 제안서는 이 두 간극을 **줄이는** 방향의 실행안이다. 상세 진단·리스크 매트릭스는 동봉 분석 리포트 참조.

## 3. 제안 A — 졸업작 스코프 재정의 (가장 중요)

> **핵심: "2028 이월"을 실패가 아니라 기본 시나리오로 받아들이고, 90초 트레일러를 진짜 1차 산출물로 재정의한다.**

테크니컬·QA 평가가 일치한다 — 복무(~2027.3) 후 실개발 약 2~3분기에 이무기 풀 프로덕션(모델·리깅 미산정, 실질 60~100일+)·전투·AI·VFX·사운드·트레일러를 직렬로 욱여넣는 현 일정은 거의 확실히 슬립한다.

- **A-1. MVP 사수선 정의:** "이무기(완성 모델) × 2페이즈 × **패턴 페이즈당 2종**(3종→선제 축소) × 전투 4~5분 완주 + 절차적 피니시 1컷 + BGM/SFX 통합 + 90초 트레일러." 이 선을 깨면 **트레일러부터 사수**하고 빌드 완성도는 후순위로.
- **A-2. 부분 Plan B 복원(D-06 재고):** 본 모델 미완 시 회색 프록시 + 완성도 높은 라이팅·연출로 **트레일러만이라도 사수**하는 안전 라인. 최대 위험 항목(이무기)에 안전장치 0인 현 상태는 단일 실패점이다.
- **A-3. 복무 +1분기 슬립 대체 일정안 명문화:** 전역 시점은 전체 계획의 단일 전제. 한 분기 밀릴 때의 대체 트랙을 일정표에 1줄로 둔다.
- **A-4. 외부 플레이테스트 3~5명 라운드를 Q3에 명시 편성:** 소울라이크 보스 공정성은 자가 1회로 못 잡는다.

## 4. 제안 B — 코어 전투 보강 (구조적 구멍 차단)

> **핵심: 현 룰셋은 자기 철학("읽기")을 자기 메커닉으로 무너뜨릴 수 있다. HP 튜닝으로는 안 풀리는 구조 문제다.**

- **B-1. 무위험 Dash 스팸 차단:** 캔슬 윈도우 전역 0~80% + Dash 무적 0.18s/쿨 0.4s + 약공 3타 쿨0 리셋이 결합해, 보스를 **읽지 않고** Dash 도배로 클리어하는 지배 전략이 성립한다. Dash를 캔슬 전역에서 제외하거나 연속 사용에 비용을 부여한다.
- **B-2. 저스트 회피(perfect dodge) 도입:** 약공 활성 직전 입력으로 발동, 성공 시 짧은 반격 보너스. 이는 **"읽기"를 직접 보상**하므로 (a)Dash 스팸을 억제하고 (b)D-11(분기 콤보 폐기) 이후 비어 있는 "표현의 여지"를 메운다 — **한 수로 두 문제 해결**. G-01("연" 메커닉)을 본게임까지 미루면 졸업작이 "표현 빈곤"으로 평가될 위험을 떠안는다.
- **B-3. 2P 예고 마진 확보:** 예고 0.55~0.7s는 선택반응시간 고려 시 마진 거의 0 → 암기로 전락. 하한을 0.6s로 올리거나 강화 돌진에 명확한 청각/색 예고를 추가한다.
- **B-4. 압박 비대칭 완화:** 풀차징·3타 적중에 **보스 경직 가산 또는 stagger 게이지**를 도입해 "내 입력이 보스를 흔든다"는 지배감을 강화. 보스 "경직만" vs 백연 3~4발 즉사의 비대칭이 카타르시스를 약화한다.
- **B-5. 정적 엔딩과 카타르시스 화해:** 피니시 직후 **백연 시선/위치를 산군 시체로 전환**해 승리 대상을 "이무기 격퇴"가 아니라 **"영역 회복"**으로 재프레이밍. 적이 안 죽어도 "공간의 주인" 감정이 성립한다.

## 5. 제안 C — 평가 환경 대응 (1회성 청중 리스크)

> **핵심: 졸업작은 숙련도 편차가 극단적인 1회성 청중(졸업 심사·퍼블리셔·KOCCA)에게 노출된다. 비숙련 평가자가 4~7분 안에 못 깨면 정점(피니시 카타르시스)을 아예 못 본다.**

- **C-1. 시연 안전장치 1개 편입:** 풀 난이도 시스템이 1인에 비현실적이라면 단일 토글이라도 — 시연 모드(이무기 HP −30%, 예고 +0.2s) 또는 누적 사망 3회 시 자동 데미지 경감. 평가 리스크를 가장 싸게 막는다.
- **C-2. 최소 서사 완결 패키지:** 시작 컷신에 산군↔백연 관계 비언어 단서 1개 + 이무기에 "백연이 아닌 여우구슬을 노린다"는 행동 단서 + 신화 비숙지 평가자용 1~2문장 컨텍스트 카드/자막 옵션. "환경 내러티브로만"의 과신을 보완한다.
- **C-3. 피니시 가이드 디제틱화:** "좌클릭 누르세요" 떠먹임을 이무기 발광·자세 변화 같은 디제틱 신호로 전환(첫 1회만 명시). "읽기"의 클라이맥스를 시스템이 가로채지 않게 한다.
- **C-4. 컷신 ESC 스킵 확정·구현:** 반복 시연 필수.
- **C-5. 클리어 정량 피드백:** 클리어 타임·노히트·피격 횟수 표시 — 외재 보상 0의 공백을 메우고 숙련 차별화를 보이는 저비용 수단.

## 6. 제안 D — 포지셔닝·문서 위생

- **D-1. 고증 표기 전환:** "한국 신화 고증" → **"전승의 재해석/평행세계"**로 일관 표기. 「구미호=백두산 산신」은 창작 재해석(전승 표준은 호랑이/백호)이다. **산군(호랑이) 스승 구조를 전면에 부각**해 충돌을 흡수한다(가장 단단한 고증 자산).
- **D-2. 벤치마크 교체:** Black Myth: Wukong(6년·~140명·$70M)은 "동양 신화 수요 증거"로만 인용하고, 비주얼·스코프 벤치마크는 **Furi·Titan Souls(보스 온리 인디)·Sekiro 보스 설계 원리**로 교체. 비주얼 현실선은 Ghost of Tsushima의 자연광·색 대비 무드.
- **D-3. 가정값 워터마크:** 7.2 밸런스 표에 "미검증 가정값" 명시 + 의존 스펙(컷신 길이·트레일러·일정)에 경고. 7.2 "9~14회"는 1P/전체 구분해 정정.
- **D-4. 보이스 명시:** 배두나·전도연은 **"톤 레퍼런스, 섭외 아님"** 부기. 졸업작 단계는 무성/플레이스홀더가 현실적.

## 8. 의사결정 요청 (기획 오너에게 — 핵심 6건)

1. **일정 기준선:** 2028 이월을 기본 시나리오로, 90초 트레일러를 1차 산출물로 재정의하는가?
2. **이무기 안전장치:** 부분 Plan B 복원 + 패턴 페이즈당 2종 선제 축소를 채택하는가?
3. **저스트 회피:** 충돌 A·표현 공백을 동시에 잡는 읽기 보상 메커닉을 졸업작 범위에 넣는가?
4. **시연 안전장치:** 접근성/시연 어시스트 최소 1개를 졸업작에 편입하는가?

## 9. 검증 계획

프로토 1주차의 진짜 게이트는 HP 수치가 아니라 구조 질문이다(상세 KPI는 분석 리포트 §8 참조).

- **H1.** 2P 예고 0.55~0.7s를 평균 플레이어가 읽는가 → 반증 시 예고·카메라 재설계
- **H2.** Dash 도배로는 클리어되지 않는가 → 반증 시 캔슬/쿨/무적 재설계
- **H3.** 이무기 9종 애니가 Q3 내 처리 가능한가 → Q2 말 진척률로 조기 판정
- **H4.** 환경 내러티브만으로 신화 비숙지 평가자가 테마를 인지하는가 → 시연 후 인터뷰
