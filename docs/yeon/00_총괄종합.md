## 1. 한 줄 결론

> **이 기획은 1인 졸업작 기준으로 스코프 절제와 문서 밀도가 상위권이다. 그러나 두 개의 구조적 간극이 프로젝트 전체를 관통한다 — (1) "산신 구미호"라는 USP는 본게임(1401)에 있는데 실제 산출물은 그것을 거의 증명하지 못하는 졸업작(946 단일 보스전)이고, (2) 정밀하게 적힌 수치·타이밍·일정이 전부 "프로토 1주차 전 가정값" 위에 확정처럼 서술돼 있다. 정합성과 정직함은 분명한데, 그 정합성이 미검증 가정과 단일 실패점들 위에 서 있다.**

여섯 직군이 서로 다른 출발점에서 같은 결론에 수렴했다: 컨셉팀은 "컨셉은 본게임에, 산출물은 졸업작에 있다"고, 레퍼런스팀은 "졸업작 USP는 메커닉이 아니라 전적으로 아트·연출·캐릭터에 의존한다"고, QA팀은 "본게임은 비전 선언이지 설계가 아니다"라고 했다. **세 진단은 한 문제의 세 얼굴이다.**

## 2. 전 직군 공통 합의 (이견 없음)

1. **스코프 절제는 진짜 강점이다.** 단일 아레나·시스템 축소(메뉴/세이브/스킬트리/인벤토리 컷)·콤보 루트 분기(D-11) 폐기·"연" 메커닉 신설 보류는 1인 졸업작에 정직한 결정이다. 이 규율을 깨지 않는 것이 1순위 방어선.
2. **"가정값"을 확정값처럼 서술한 것이 문서의 근본 결함이다.** 백연 HP 1,000 외 거의 모든 수치(이무기 HP·데미지·페이즈 길이·보스전 4~7분·예고 타이밍)가 프로토 후 확정 예정인데, 컷신 길이·트레일러·일정이 이를 확정 스펙처럼 인용한다. (메커니즘·UXUI·QA 공통)
3. **졸업작 산출물은 "전투 완성도로 Primary 확보 + 서사·USP는 떡밥"으로 역할을 솔직히 분리해야 한다.** 단일 보스전이 본게임의 USP를 다 전달하려다 둘 다 얕아진다. (컨셉·QA·레퍼런스 공통)
4. **이무기 에셋이 최대 단일 병목이고, 거기에 Plan B가 없다.** Plan B 전면 폐기(D-06)는 최고 위험 항목을 무방비로 둔 결정. (테크니컬·QA 공통)
5. **단일 난이도·접근성 공백은 "기능 누락"이 아니라 "평가 환경 리스크"다.** 졸업 심사·퍼블리셔·KOCCA는 숙련도 편차가 극단적인 1회성 청중이며, 비숙련 평가자가 4~7분 안에 못 깨면 정점(피니시 카타르시스)을 아예 못 본다. (UXUI·QA 공통)

## 3. 반드시 해소해야 할 핵심 충돌 (Director 결정 필요)

여러 직군이 독립적으로 짚은 구조적 모순이다. **이것을 먼저 정리하지 않으면 하위 설계가 흔들린다.**

### 🔴 충돌 A — "읽기" 철학 vs 무위험 Dash 스팸 (최우선·구조적)
캔슬 윈도우 전역 0~80% + Dash 무적 0.18s/쿨 0.4s + 약공 3타 적중 시 Dash 쿨 0 리셋이 결합하면, 보스를 **읽지 않고** Dash 도배로 클리어하는 지배 전략이 성립한다. 이는 D-11(분기 콤보 폐기)이 막으려던 "메커닉이 읽기를 대체"하는 실패의 다른 형태다.
- **해법(메커니즘팀):** Dash를 캔슬 전역 허용에서 제외하거나 연속 Dash에 비용 부여. **+ 저스트 회피(perfect dodge) 도입** — 읽기를 직접 보상하므로 충돌 A와 "표현의 여지 공백(R1)"을 동시에 해결.
- **결정 필요:** 저스트 회피를 졸업작 범위에 넣는가? (G-01을 본게임까지 미루면 졸업작이 "표현 빈곤"으로 평가될 위험)

### 🔴 충돌 B — 단일 감정(카타르시스) vs 정적 엔딩(적 후퇴·미소멸)
"내가 이 공간의 주인"을 노리는데 이무기가 죽지 않고 후퇴 + 정적으로 끝나, 졸업작 단독 감상자에겐 "이긴 건가?"의 미완감이 된다.
- **해법(컨셉팀):** 피니시 직후 **백연 시선/위치를 산군 시체로 전환**해 승리 대상을 "이무기 격퇴"가 아니라 "영역 회복"으로 재프레이밍. 그래야 적이 안 죽어도 "주인" 감정이 성립.
- **결정 필요:** 졸업작 결말 연출 규칙을 이 방향으로 고정하는가?

### 🔴 충돌 C — 미검증 가정 위에 쌓은 확정 일정/스펙
밸런스·타이밍·페이즈 길이가 전부 가정인데 4~7분·트레일러·2027 Q4 마감이 이를 전제로 짜였다. HP만 튜닝 변수로 두면 충돌 A·압박 비대칭 같은 **구조 문제는 안 풀린다.**
- **해법(전 직군):** 7.2 표에 "미검증 가정값" 워터마크 + 의존 스펙에 경고. 프로토 1주차의 진짜 게이트를 HP가 아니라 **"Dash 도배로 클리어되는가" / "2P 예고 0.55s를 평균 플레이어가 읽는가"**로 정의.
- **결정 필요:** 가정/확정 분리 표기를 채택하는가?

### 🟡 충돌 D — 서사 전달 채널 부재 ("환경 내러티브로만"의 과신)
산신·위계·산군 1500년 사제관계·이무기 동기(여우구슬 오인 비극)가 전부 GDD 문서에만 있고 인게임 전달 수단이 사실상 없다. 신화 비숙지·해외 평가자에겐 카타르시스의 토대 자체가 빈다.
- **해법:** 시작 컷신에 산군↔백연 관계 비언어 단서 1개, 이무기에 "백연이 아닌 여우구슬을 노린다"는 행동 패턴 단서, 시연용 1~2문장 컨텍스트 카드/자막 옵션.
- **결정 필요:** 졸업작에 "최소 서사 완결 패키지"를 명시 설계하는가?

## 4. 합의된 리스크 우선순위 (Top)

1. **이무기 에셋 병목 + Plan B 부재 + Q3 직렬 충돌** — 모델·리깅 일수가 산정조차 안 됨(실질 60~100일+). 같은 분기에 AI·VFX·사운드 병행은 산술적 불가에 근접. 최고 위험에 안전장치 0. (테크니컬·QA 1순위)
2. **복무 종료(2027.3) 단일 실패점** — 전체 일정의 전제인데 버퍼·대안 트랙 없음. 한 분기 밀리면 Q4 1차 자동 붕괴.
3. **미검증 가정의 확정화** — 프로토에서 수치/타이밍이 깨지면 코어 루프 연쇄 재설계.
4. **단일 난이도·접근성 공백** — 1회성 평가 환경에서 양극 청중 불만족 → 트레일러 인상까지 잠식.
5. **USP 미증명 + 콘텐츠/리플레이 빈약** — 졸업작 USP는 아트·연출 의존, 외재 보상 0·단일 엔딩으로 반복 시연 매력 감소.
6. **서사 전달 실패 + 정적 엔딩 충돌** (충돌 B·D).
7. **포지셔닝 기대치 함정** — Black Myth: Wukong(6년·~140명·$70M)을 1인 졸업작 벤치마크로 차용. → 수요 증거로만 인용하고 벤치마크는 **Furi·Titan Souls·Sekiro 보스 설계 원리**로 교체.

## 5. 고증 판정 (레퍼런스팀 요약)

7개 주장 중 ◎3 / ○1 / △2 / ✗1. **무너지는 곳은 단 둘인데 그것이 게임의 한 줄 정의다:** 「구미호 = 백두산 산신」은 직접 전거 없는 **창작 재해석**(전승상 백두산 산신의 표준은 호랑이/백호). 반면 946년 백두산 대분화·이무기/여의주·산군(=호랑이 산신)은 **고증적으로 단단**하다.
- **권고:** "한국 신화 고증" 대신 **"전승의 재해석/평행세계"**로 일관 표기(5.1 평행세계 전제는 영리한 방어선). **산군(호랑이) 스승 구조를 전면에 부각**해 #1·#2 충돌을 흡수. 여우구슬↔여의주 대체는 창작이나 "처음부터 불가능한 확신"으로 내적 정합 확보됨.
