# 게임 기획서 (GDD) — 「소실점 / VANISHING POINT」 (가제)

> 선형 싱글플레이 현대전 FPS · UE5 · Steam(PC)
> 8개 디자인 직군의 토론·협의를 단일 문서로 종합한 통합 기획서. 상세 근거는 `docs/design/00~17` 참조.
> **모든 게임플레이 수치는 제안값**(플레이테스트 전 튜닝 기준).

## 1. 개요

| 항목 | 내용 |
|---|---|
| 가제 | **「소실점 / VANISHING POINT」** (부제 「철책선」 병기 가능) |
| 장르 | 선형 싱글플레이 1인칭 슈터(현대전) |
| 엔진/플랫폼 | Unreal Engine 5 / Steam (PC) |
| 분량 | 캠페인 7 챕터 (≈6~8시간, 챕터당 예산 상한 확정 필요) |
| 배경 | **실제 한반도** (대한민국 vs 북한), 정전 70여 년 DMZ 긴장 고조 |
| 주인공 | 김동수 대위 — 「창(槍) 특임대」(707 모티브, 부대명만 가상화) |
| 한 줄 컨셉 | **통제할 수 없는 전장 속, 유능하지만 무력한 한 군인의 이야기.** |
| 주제 | 통제의 환상 — 시스템(미표시 자원)과 서사(엘리트의 붕괴)가 한 주제로 수렴 |

**정체성:** 모든 자원(탄약·체력·무기 신뢰성·시간)이 화면에 표시되지 않는다. 플레이어는 숫자가 아니라 **소리·반동·화면의 변화**로 자신의 상태를 읽는다. 캠페인 위주의 강한 연출·페이싱이 중심이며, 멀티/라이브서비스는 없다.

## 2. 디자인 기둥 & 핵심 긴장 루프

**7대 기둥**
1. HUD 최소화(지도·게이지·잔탄 미표시) + 접근성 토글 별도
2. 격발 3상태 분리 — 정상 / 탄 소진(딸깍, 소리 O) / 기능고장(갑자기 안 나감)
3. 탄창 무한 + **총 탄알 유한** 재장전(R키, 무손실 회수)
4. 무기 기능고장 저확률 + 수동 배제
5. Bitter Ending(씁쓸하되 비극 아님)
6. 선형 구조(캠페인)
7. 미표시 자원 관리가 곧 생존 메카닉(4축)

**핵심 긴장 루프 (4축 동시 압박, 전부 미표시)**
> 정찰(공간 읽기) → 교전 → **유한 탄약을 소리로 추적** → 재장전 타이밍 도박(노출) → (저확률) 기능고장 → 수동 배제 도박 → HP 위험 관리 → 해소(안전구간) → 다음.

4축 = ①유한 탄약(풀 고갈) ②재장전 타이밍/노출 ③무기 신뢰성(잼) ④체력. 탄약 유한화로 1차 토론의 "평시 교전 긴장 공백" 리스크를 해소했다. **단, 4축을 매 구간 동시에 최대로 조이지 않는다**(→ §12 "1주+1보조" 원칙, 운사 방지).

## 3. 세계관·설정 (상세: `design/10`)

- **시대·무대:** 근미래의 "지금". 정전 70여 년 한반도, 전면전 직전의 회색지대. 전면전이 아니라 **통제 가능하다 믿어지는 한 건의 작전**이 통제를 벗어나는 이야기로 좁힌다.
- **아군:** 대한민국 국군. 주인공 부대 = **「창(槍) 특임대」**(호출부호 Lance, 707 모티브 가상명). 김동수가 Lance-1 팀장.
- **적:** 북한(조선인민군) 정규 보병 + 비대칭 침투조. 개개인은 위협적이지 않으나 "끝없이 밀려오는 통제 불가능한 변수"로 연출.
- **제3의 변수(회색):** 후반에 아군 상부의 정치적 판단·통신 두절·우군 오인사격 등 **"적이 아닌 체계"가 통제 상실의 진짜 원인**으로 드러남.
- **작전 「소실점」:** 북한의 접경 통신중계소 점거 + 요인 납치에 대해 단독 침투 → 구출 → 지휘노드 제거 → 탈출. 표면상 "깔끔한 한 건"이 단계적으로 붕괴.
- **소재 가드레일(필수):** 반전(反戰)·개인 서사 중심, 진영 중립(실명 정치인/정권 미언급, 도발 주체를 "지휘부 일부의 폭주"로 한정), **북한 주민과 체제 분리**(적 병사는 명령에 묶인 인간으로 최소 입체화), 군 묘사 면책 고지. (→ §15)

## 4. 캐릭터 (상세: `design/11`)

**김동수 대위(주인공).** 극단적 엘리트주의 + 다혈질. 모든 인간을 "유능/무능" 단일 축으로 분류. 심층 동기는 **통제 상실에 대한 공포**(엘리트주의는 그 공포의 갑옷).
**아크 — "엘리트주의는 깨지지 않고, 멸시의 대상이 바뀐다":** 적(1막) → 무능한 아군·체계(2막) → **과거의 자기 자신(엔딩)**. "나는 틀렸다"고 깨닫지 않는다. 여전히 무능을 경멸하되, 그 화살이 처음으로 자기에게 박힌다(신념의 부메랑).

| 인물 | 역할 |
|---|---|
| 민 중사 | 거울/안티테제. "다 통제하신다면서 왜 화가 나십니까?" **끝까지 생존**(신파 차단), 마지막 무심한 눈빛이 비수 |
| 하 일병 | 서툰 신참. 동수가 경멸하나, 통제 환상 없이 변수를 견디는 태도 = 엔딩에서 깨닫는 "무능한 과거의 자신"의 앵커 |
| 상부 지휘관 | 시스템의 화신. 성공만 요구, "영웅" 칭호가 공허를 완성 |
| 적 지휘관 | 거울상 적. 그 역시 통제 불가 상황에 던져진 "또 다른 김동수" |

## 5. 시나리오·미션 구조 (상세: `design/11`)

3막 / 7 챕터. 메카닉 학습 곡선·아크 단계와 동기화.

| CH | 미션 | 핵심 | 신규 메카닉 | 격발 | 아크 |
|---|---|---|---|---|---|
| 1 침투 | 강원 산악 야간 능선, 무음 제거 | 기본 사격·이동, 풍족 기준선 | 정상만 | 확신 |
| 2 장악 | GOP/DMZ 철책·지뢰, 교통호 교전 | 무기 픽업, 이동 다양성 | 정상 | 확신 |
| 3 첫마찰 | 임진강 수몰 폐촌(정보 오류) | **탄 소진 "딸깍" 첫 등장** | 정상+딸깍 | 방어 |
| 4 기능고장 | 점거 통신중계소 CQB | **첫 jam(스크립트)**, HP 청각화 | 3상태 | 방어 |
| 5 거울 | 북한 남침 땅굴·벙커 | **탄약 고갈 정점**, 적 지휘관 대면 | 3상태 | 격화 |
| 6 강행 | 임진강 제방·개활 논 | **무력감 절정**, 연속 잼·2차 고갈 | 연속 jam | 격화 |
| 7 완수/공허 | 고지 OP→무너진 다리(피날레) | 8종 회수, **마지막 jam 비트** | 엔딩 jam | 완수→전환 |

**Bitter Ending (확정안 = A안 임무완수+의미증발 × C안 마지막 jam):** 임무 100% 완수. 죽은 줄 알았던 마지막 적 앞에서 통제를 완성하려 격발 → **딸깍(고장)**. 손이 자동으로 배제에 들어가지만 이번엔 무기를 향한 욕이 나오지 않는다. 작동 안 하는 자기 총과 맞은편 무능한 적의 떨리는 손 위로 1막의 자신이 겹친다. jam 해소/K-5 전환(플레이어 마지막 입력)으로 적 처치, 임무 성공. **음악 고조·승리 UI·슬로모 금지. 마지막 소리는 빈 격발음 "딸깍"의 잔향.** ("허무"가 아닌 "대가 있는 상실"로 읽히게 과정 의미를 정산.)

## 6. 코어 게임플레이 시스템 (상세: `design/12`)

### 6.1 탄약 모델 (오너 확정)
- **탄창(매거진) 무한:** 개별 탄창 수를 세지 않음. R키로 언제든 재장전.
- **총 탄알(탄약 풀) 유한:** 바닥나면 재장전 불가. 이것이 진짜 자원.
- **재장전 시 현재 탄창 잔탄은 풀로 무손실 회수** → "자주 갈아라"가 권장. 비용은 재장전 모션 중 노출(0.4~0.7s).
- **전부 미표시.** 풀이 한 탄창 미만이면 부분장전 → 딸깍 빈도↑ = **고갈 단서**.
- 구경별 풀(5.56/9mm/적 무기), 적 사살·환경 픽업 보충. 픽업 드랍은 교전 중심에 생성(**픽업=노출 동선**).

### 6.2 격발 3상태 (오너 확정)
| 상태 | 청각 | 의미 | 대응 |
|---|---|---|---|
| 정상 | "탕"+반동·머즐플래시 | 정상 | 계속 사격 |
| 탄 소진 | **"딸깍"(맑은 공이 격발음), 반동·화염 없음** | 탄창 빔 | **R 재장전** |
| 기능고장 | **갑자기 안 나감(둔탁/무음, 딸깍과 구분)** | 무기 고장 | **수동 배제** |
두 "안 나감"을 소리·시각·햅틱·입력 4중으로 구분(→ §10). **오디오 차별화가 시스템 성패의 핵심 PoC.**

### 6.3 이동 메카닉 (8종)
걷기 / 달리기 / 앉기 / 포복 / 슬라이딩 / 린(좌우 기울이기) / 점프·볼트 / 회피 대시. + 총기 거치(상태). 대부분 "안전하게 갈/주울/치료할 시간을 만드는" 도구로 기능(→ §11 전용 공간).

## 7. 전투 시스템 (상세: `design/12`)

- **사격:** 히트스캔. 분산(K-13 ADS 0.6°, 발당 블룸 +0.25°, 회복 0.4°/s), 반동(수직 +0.45°/발, 초탄 3발 가중, 수평 드리프트 학습 가능). **거치 보정**(수직 -60%/수평 -70%/분산 -50%, 단 이동 불가+시야 ±35° = 강력하나 고정 리스크).
- **기능고장(시그니처):** `P_jam = Base × (1+(100−Condition)/100×k)`, **k=2**(밸런스 검증), base K-13 0.4%/K-5 1.2%/적무기 2~4%, **실효 캡 12%**. 잼 3종 = 불발(Tap, 0.6s)/걸림(Tap-Rack, 1.1s)/이중급탄(Hold-clear, 1.8s). **안전장치:** 연속잼 쿨다운(복구 후 1.5s P=0), 첫 교전 잼 0% 보호, 잼 직전 0.3s 시각 단서 의무. jam은 과사격/과부하 누적과 연동(랜덤 아님), 스크립트 잼은 CH4·CH7 확정 트리거.

## 9. 체력·생존 (상세: `design/12`)

**2단 체력(미표시):** 아머(자동 리젠, 피격 3s 후 25/s) + 생체(자동 회복 없음, 의료품 2.5s/체크포인트). 피해 아머→생체 순.
4단계 화면효과: 아머손상(청백 플래시) / 생체(붉은 비네팅·심박) / 생체 중상(채도저하·호흡) / 위독(흑백·이명·이동/반동 페널티). **즉사 금지**(풀HP 최소 2회 피격 생존, 적 1탄 캡 정예 ≤18).

## 10. UI/UX (상세: `design/15`)

- 기본 **Pure**(전부 미표시). 원칙: 제거하는 건 표상방식이지 정보가 아니다 → 모든 정보를 최소 2채널로 디제시스 재배치, 키마 유저는 시각+청각 주채널(햅틱 보조·단독 금지).
- **딸깍 vs 잼 4중 변별**(청각: 맑음 vs 둔탁/무음 / 시각: 후퇴 고정 vs 중간 걸림 / 햅틱: 2펄스 vs 거친 진동 / 입력: R 작동 vs R 무반응). 오입력 방지(잼 상태 R=거부 피드백) + 입력 버퍼링.
- **미표시 탄약 풀 고갈 = 점진 곡선**(딸깍 빈도↑ → 부분장전 체감 → 재장전 사운드 3변형[꽉참/절반/거의빔 긁힘음] → "Last mag" 무전). 고갈사 = 항상 "신호 무시의 결과"=공정.
- **접근성(필수):** Pure/Assisted(기본 권장)/Full 프리셋 + 청각장애(청각 단서 전부 시각 대체)·색맹(명도/텍스처/패턴)·광과민(플래시 제한)·멀미(셰이크/블러 슬라이더)·입력(잼 복구 홀드↔토글) 토글. "쉬운 모드"가 아닌 "보는 방식 선택"으로 프레이밍.
- **온보딩(첫 30분, 팝업 없이 김동수 무전으로):** 위험 순서로 학습 — 격발(딸깍)→탄약 풀→HP→잼(불발만). 실패해도 안 죽는 안전 마진.

## 11. 레벨·미션 디자인 (상세: `design/13`)

- **공간 = UI.** 무마커 내비게이션 3층: L1 매크로(멀리 보이는 단 하나의 랜드마크, 동시 2개 금지) / L2 메조(통과 가능·불가의 건축 대비) / L3 마이크로(핏자국·탄피·동료의 등, 아레나 출구에 집중). DMZ 철책·지뢰표지는 실제로 길을 막으므로 **고증과 내비가 합치**(강점).
- **자원의 공간화:** 픽업 밀도가 잔량 게이지를 대신 — 풍족(①②)→인색(③④)→고갈(⑤)→잔혹(⑥)→바닥(⑦) 단조 감소. 갱도/제방은 의도적 고갈→적무기 픽업 강제.
- **페이싱:** 단위 4박자(긴장-교전-해소-회복창), 안전 포켓이 아머 리젠 기회. 위기 3정점(CH4 잼 충격 → CH5 고갈·잼 최고점 → CH6 무력감 고원), CH7 의도적 하강 후 딸깍으로 0 수렴.
- **이동 8종:** 챕터별 전용 학습 공간 → 후반 복합 응용, CH7에서 8종 회수(여정 종합).
- **라이트모티프 미러링:** 철책(②진입선 → ⑦갇힘선), 다리(③원경 → ⑦무너진 다리, 닿음=좌절), 안개(보호막→수의), 무전(클리어→무응답→침묵). 엔딩 프레임에 4모티프 동시 수렴.

## 12. 밸런스 (상세: `design/14`)

- **"1주 압박 + 1보조" 원칙:** 구간별 주 1개(60~70%)+보조 1개(30~40%), 나머지 배경. 4축 동시 최대 압박 금지(운사 방지).
- **운사 방지 4장치:** 모든 죽음에 사전 단서 / 즉사 금지 / 12~18분마다 세이프룸 / 사후 데스캠 원인·방향.
- **적:** 보병(유효HP 70, 3발, 엄폐·점사) / 침투조(95, 4발, 측면·수류탄) / 정예(140, 6발, 압박). **이동상태별 적명중:** 정지 ×1.0("멈추면 죽는다"), 걷기 ×0.8, 달리기/슬라이딩 ×0.55, 노출 동선 ×1.15.
- **탄약 곡선:** 풀30 경고시작→풀0, **선형(비지수)**, 경고~고갈 2~3킬 버퍼. 갱도/제방 고갈 안전선(진입 전 보장 상자, 교전 총량 풀70% 캡, 막판 적무기 보장 드랍).
- **난이도:** 단일 코어 + 축별 접근성 슬라이더(조준 보조/적 데미지 ×0.6~1.0/잼 k1.5~2.0/탄약 시작 +0~90/단서 강화[기본 on]). 잼은 완화 방향만 조정.
- **튜닝 Top6:** ①부분장전 시작선+딸깍 곡선 ②잼 k·캡 ③적 1탄 데미지 캡 ④보급 간 교전 총량 캡 ⑤이동상태별 적명중 ⑥적 유효HP.

## 13. 보상·동기 (상세: `design/14`)

외재 보상(레벨업·언락·수집) 없음 → 보상 = **생존경제 + 서사 + 숙련 표현**. "매 5~10분 받는 것" 감사표(탄약 보급 3~6분 / 픽업 무기 8~12분 / 서사 비트 5~10분 / 난관 돌파 10~15분 / 세이프룸 12~18분). 숙련 가시화는 수치 없이 조용한 사운드로(무손실 회수·무잼 연속). 보상 = "다음 장면을 볼 자격"(Bitter 톤과 정합).

## 14. 테크니컬 (UE5) (상세: `design/16`)

- **GAS 전면 비채택**(싱글). 권장 (A) GameplayTags만 + 타이머 기반 상태효과 컴포넌트(MVP), 상태효과 늘면 (B) GAS Attribute/Effect 부분. **GameplayTag는 처음부터.**
- **Enhanced Input** 상태별 IMC 스택. **데이터 주도** 무기(PDA + DataTable 하이브리드).
- **탄약:** 수치 풀 + 가상 탄창 "부족분만 충전"(무손실), 탄창 객체 추적 없음. **잼:** Condition 기반 per-shot 롤(`FRandomStream` 재현 가능 → 스크립트 잼/QA), 안전장치.
- **비-HUD 피드백:** 격발 3상태 **MetaSounds(최우선 M0 PoC)** — 블라인드 테스트로 "세 소리만으로 100% 구분"이 통과해야 디자인 성립. HP는 MPC 포스트프로세스.
- **이동:** CMC `CustomMovementMode`(슬라이딩/포복/거치/경량 엄폐), ABP 우선(Motion Matching 보류). **AI:** StateTree/BT + **청각 Perception 연동**(무소음 플레이가 전술적 의미)·엄폐(EQS)·억압.
- **캠페인:** World Partition 아님 → 전통 Level Streaming + `USaveGame` 체크포인트 + `Level Sequencer`(무전 경량). **Steam:** OnlineSubsystemSteam(업적·클라우드세이브), Steam Input.

## 15. QA·리스크 & 소재 가드레일 (상세: `design/17`)

**1차 모순 해소:** 무한재장전↔잔탄미표시(R5)·빈탄창vs잼 구분(충돌B)·톤(R3) **해소**. 평시 긴장 공백도 탄약 유한화로 해소.
**치명 리스크 Top:** ①실한반도/북한 소재(최대) ②4축 미표시 운사 ③딸깍/잼 변별 실패 ④단일 엔딩+선형 스코프/리플레이 ⑤김동수 비호감.
**★소재 가드레일(부대명 가상화만으론 불충분 — 5종 세트):** (a) 진영 비대칭 회피·개인 서사 중심 (b) 북한 주민/체제 분리·실존 지도자 캐리커처 금지 (c) 군 묘사 면책 고지·"가상 부대" 명시 (d) 중국 제외 가정 매출모델·지역별 빌드 (e) 등급 역설계. + "반전적 인간 드라마" 톤 헌장.
**운사 방지:** 디제틱 신호 의무화, 동시성 상한, 난이도별 미표시 분리(표준 1~2축/하드코어 4축), 축별 온보딩.

## 16. 개발 로드맵

- **MVP(수직 슬라이스):** 무기 2종+픽업 1종, 격발 3상태 완성, 잼 3종+안전장치, **M0=오디오 3상태 PoC + 블라인드 테스트**, 이동 4~5종, HP 2단 PP, AI 보병 1종(청각·엄폐·억압), CH4 구간(스크립트 잼 검증).
- **최우선 검증 가설:** ①4축 미표시 사망 귀인(신규 70%+ "왜 죽었나" 정확) ②딸깍/잼 변별(정상 90%/소음 75%) ③소재 수용성(**정치성향 균형·외부 표본**, 진영 편중 없음).
- **가장 먼저 잠글 수치:** enemy-TTK / 적 명중률(이동상태별) / 잼 확률(k·캡) / 부분장전 시작선·딸깍 곡선.
- **출시 전 게이트:** 법무 리뷰·톤 가드레일 문서·등급 사전 확정·지역별 빌드·접근성(청각0/색맹/키마) 3종 통과.
