## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 선형 싱글플레이 1인칭 슈터(현대전) |
| 엔진 / 플랫폼 | Unreal Engine 5 / Steam (PC) |
| 시점 | 1인칭 |
| 분량(목표) | 캠페인 6~8 챕터 _(확정 예정)_ |
| 타깃 | 몰입형·하드코어 지향 싱글 FPS 팬 + 내러티브 슈터 팬 |
| 한 줄 컨셉 | **통제할 수 없는 전장 속, 유능하지만 무력한 한 군인의 이야기.** |

핵심 정체성: **모든 자원(탄약·체력·무기 신뢰성·시간)이 화면에 표시되지 않는다.** 플레이어는 숫자가 아니라 소리·반동·화면의 변화로 자신의 상태를 읽는다.

## 2. 디자인 기둥 & 핵심 긴장 루프

**7대 기둥**
1. HUD 최소화 (지도·게이지·잔탄 미표시) + 접근성 토글 별도 제공
2. 격발 3상태 분리 — 정상 / 탄 소진(딸깍, 소리 O) / 기능고장(갑자기 안 나감)
3. 탄창 무한 + **총 탄알 유한** 재장전 (R키)
4. 무기 기능고장 저확률 발생 + 수동 배제
5. Bitter Ending (씁쓸하되 비극 아님)
6. 선형 구조
7. 미표시 자원 관리가 곧 생존 메카닉 (4축)

**핵심 긴장 루프 (4축 동시 압박, 전부 미표시)**
> 정찰(공간 읽기) → 교전 개시 → **유한 탄약을 소리로 추적** → 재장전 타이밍 도박(노출) → (저확률) 기능고장 → 수동 배제 도박 → HP 위험 관리 → 해소(안전구간) → 다음.

4축 = ①유한 탄약 ②재장전 타이밍/노출 ③무기 신뢰성(잼) ④체력. → 1차 토론의 "평시 교전 긴장 공백" 리스크를 탄약 유한화로 해소.

## 4. 캐릭터

**김동수 대위 (주인공)** — 극단적 엘리트주의 + 다혈질. 가상 정예 특수부대 소속(707 모티브, 가상화).
아크: **"엘리트주의는 깨지지 않고, 그 경멸의 대상이 바뀐다"** — 끝까지 무능을 경멸하되, 마지막에 그가 가장 경멸하는 무능한 인간이 "상황을 통제할 수 있다고 믿었던 과거의 자신"이 된다.

_(조연·적 등장인물은 시나리오 에이전트 산출물 통합 예정.)_

## 6. 코어 게임플레이 시스템

### 6.1 탄약 모델 (확정)
- **탄창(매거진) 무한:** 개별 탄창 수를 세지 않음. R키로 언제든 재장전.
- **총 탄알(탄약 풀) 유한:** 바닥나면 재장전 불가.
- **재장전 시 현재 탄창 잔탄은 탄약 풀로 무손실 회수.** → 자주 갈아끼울 수 있으나 총량은 안 줄므로 진짜 압박은 "총 탄약 고갈".
- **현재 탄창 잔탄·총 탄약 모두 미표시.** 소리·체감으로만 추적.
- 구경별 풀(5.56mm / 9mm / 적 무기 구경), 적 사살·환경에서 픽업 보충.

### 6.2 격발 3상태 (확정)
| 상태 | 청각 신호 | 의미 | 대응 |
|---|---|---|---|
| 정상 발사 | "탕" + 반동·머즐플래시 | 정상 | 계속 사격 |
| 탄 소진 | "딸깍" 공이 격발음(소리 O), 반동·화염 없음 | 탄창 빔 | R 재장전 |
| 기능고장 | 갑자기 안 나감(딸깍과 구분되는 둔탁/무음) | 무기 고장 | 수동 배제 |

### 6.3 이동 메카닉
엄폐 / 슬라이딩 / 달리기 / 걷기 / 점프 / 총기 거치 / 앉기 / 포복. _(전투적 의미·전용 공간은 7·11장.)_

## 9. 체력·생존

- **2단 체력:** 아머(자동 리젠, 전투 이탈 후) + 생체(자동 회복 없음, 회복아이템/체크포인트만). 미표시.
- 전달: 포스트프로세스(채도저하·혈흔 비네팅·흔들림) + 오디오(심박·이명·호흡). 중상 시 이동·반동 페널티.
- _(수치는 전투 v2 통합.)_

## 10. UI/UX

- 기본 **Pure**(전부 미표시, 디제시스·사운드·화면효과 전달).
