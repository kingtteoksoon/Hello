# 05. 밸런스·보상 직군 의견서

## 1. 무한 탄약 환경의 난이도 설계 원칙

탄약 표시 제거 + 무한 재장전 = 전통 FPS의 핵심 압박원 둘(자원 고갈 공포, 관리 의사결정) 소멸. 못 메우면 "맞을 때까지 쏘는 사격장".

**압박원 재배치(우선순):**
- **시간/노출:** 리로드=무방비 구간. 리로드 길게(K-13 2.0~2.4s, K-5 1.6~1.9s), 탄창 작게(K-13 **25발**, K-5 **12발**) → "언제 리로드하느냐"가 진짜 의사결정.
- **공간/포지셔닝:** 적 화력 집중·측면 우회로 "한 자리 고수=죽음".
- **정보 결핍 자체:** 인지 부하·압박(단, 운사 보정 필요).
- **TTK 비대칭:** player-TTK 짧아도 OK, enemy-TTK 짧게 → "먼저 본 쪽이 이긴다".

**핵심 원칙:** 무한 탄약은 "쏘는 행위"에서 압박을 제거한 대신 **"쏘지 못하는 순간(리로드·이동·엄폐 전환)"에 압박을 몰아넣는 게임.**

## 2. 적 설계 밸런스 (제안값, 일반 보병)

적은 얇고·빠르고·수 적당·똑똑하게. 두꺼우면 무한탄약과 결합해 "스펀지에 무한 사격".
- **체력:** 헤드 1발 / 흉부 2~3발(K-13). 방탄복 적 흉부 4~5발 또는 헤드/하지 노출 요구 → 조준 강제.
- **정확도:** 정지·노출 시 근거리 60~75%, 슬라이딩/달리기 중 15~30% → 이동에 생존 보상.
- **enemy-TTK:** 노출 시 0.8~1.5s. 너무 짧으면(<0.6s) 정보결핍과 결합해 즉사 좌절.
- **동시 교전:** 일반 2~4명, 클라이맥스 5~7명(상한 관리, 6~7명 동시 사선은 운사).
- **AI 공격성:** 중상. 엄폐 플레이어에게 수류탄(쿨다운 길게)·연막·플랭킹. "교전 개시 1~2명 + 압박/우회 1~2명" 역할 분담.

**근거:** 위협은 '맷집'이 아니라 '치명성과 포지셔닝'에서.

## 3. 무기 밸런스 — 픽업이 밸런스를 깨지 않게

- **K-13(주력 기준):** 모든 적 밸런스의 기준 무기.
- **K-5(보조·최후수단):** 약하되 리로드/꺼내기 빠름, 헤드샷 가치↑.
- **픽업:** 다양성·상황적 우위, 상시 상위호환 금지.

**픽업 제어 장치(무한탄약이라 일반적 탄약 제한이 안 통함):**
- **A — 픽업은 무한탄약 제외, "주운 탄창만".** (가장 강력. 아군 무기만 무한 → 기둥과 비충돌)
- **B — 트레이드오프 내장**(이동 페널티·긴 리로드·심한 반동).
- **C — 기능고장 확률 차등**(픽업은 정비 불명 → 잼 확률↑).
- **D — 희소·상황 한정 배치**(특정 인카운터에만).

구도: **신뢰성·무한탄약 K-13=척추 / 픽업=짧고 강한 스파이크 / K-5=안전망.** 우열을 단순 DPS 아닌 "탄약 출처·신뢰성·기동성" 다축 분산.

## 4. 기능고장 확률의 밸런스 영향

유일한 추가 생존/리스크 메카닉이라 무게 큼. 무한탄약 게임에서 "탄약 고갈" 패배가 없으니, 잦으면 **유일한 통제불가 패배 원인** + HP 미표시와 결합 시 "왜 죽었는지 모르는 죽음" → **확률은 매우 보수적으로.**

제안: K-13/K-5 **0.2~0.5%/발**(탄창당 최대 1회), 픽업 2~4배 가중, 배제 1.0~1.5s.

**난이도별 조정 — 입장: 조정하되 한 방향(완화)으로만.** 기본(하드코어) 값을 정식으로, 쉬운 모드에서만 낮추거나 0. 잼은 본질이 "운"이라 고난도에서 올리면 운사만 증가(나쁜 어려움). **난이도 상향은 적 설계로, 잼은 완화 방향으로만.**

## 5. 난이도 모드 정책

정체성(HUD 최소·정보결핍·Bitter)은 단일 하드코어 비전과 결합되나 접근성 리스크 매우 높음.

**권장: "단일 코어 경험 + 좁은 접근성 보정" 하이브리드.**
- **기본(디폴트):** 의도 그대로.
- **완화 모드:** 적 명중률·enemy-TTK·잼 확률만 완화. **HUD/잔탄은 여전히 미표시**(정체성 유지, 처벌만 낮춤).
- **상향 모드 비권장**(이미 정보결핍 천장, 운사만 증가).

근거: 정체성 기둥은 안 건드리고 불공정 죽음 변수(명중률·TTK·잼)만 다이얼. 단일 하드코어는 매력적이나 환불·평점 리스크 큼.

## 6. 보상 구조 — 외재적 보상 없는 게임의 동기

레벨업·언락·수집 없음 + Bitter Ending이라 엔딩 보상도 약함. 동기는 **내재적 보상 + 서사 진행 + 숙련감**.
- **숙련 보상(핵심):** "내가 더 잘하게 됨"이 유일·최강 보상. 이동/명중 보상을 명료하게(슬라이딩 측면 잡기=생존). **잼 운사가 잦으면 숙련 보상 붕괴** → 4번 보수적 확률 중요. 인카운터를 "정답 여러 개인 작은 퍼즐"로.
- **페이싱 자체:** 긴장→이완 곡선, 정적 구간의 환경 서사가 "쉼이라는 보상". 자원 비축 안도감 대신 **공간 통과 안도감.**
- **서사 진행:** 챕터 경계마다 "정보 해금"(스토리 비트·반전). 수집 대신 **서사 단서.**
- **체험적·미학적:** 무기 핸들링 손맛(반동·소리·애니 질감). **오디오·임팩트 피드백 투자 우선순위↑.**
- **Bitter 보정:** 중간의 작은 인간적 순간·국지적 승리로 "끝은 쓰지만 길은 의미 있었다".

**안전장치:** "매 5~10분마다 받는 무언가(새 무기·적·공간·서사·위협 패턴)"를 페이싱 표로 감사. 보상의 부재가 아니라 **"보상 종류 전환".**

## 7. 리스크 / 열린 질문

**리스크:** 운사(최상위, 정보결핍+잼+짧은 TTK 중 최소 둘은 보수적으로) > 무게감 상실(노출 압박으로 보전 안 되면 사격장) > 보상 빈약 > 픽업 무한탄약 충돌(직관 전달).

**열린 질문:** 1) 피격 피드백 어디까지?(운사 직결) 2) 회복 룰?(자동/불가/구간 — 체감 난이도 절반) 3) 잼 난이도별 조정 최종 결정 4) 픽업 탄약 모델(장치 A) 채택+톤 충돌 커뮤니케이션 5) 단일 하드코어 vs 접근성 보정의 상업/예술 우선순위.

**가장 먼저 잠글 3개:** enemy-TTK, 적 명중률(이동 상태별), 기능고장 확률. 이 셋이 "공정한 어려움 vs 운사"의 경계.
