# 09. 확정 결정 v2 (오너 + Director) — 2차 설계 기준선

> 1차 토론(00~08) 이후 오너 결정과 Director 판단으로 핵심 사양을 확정한다. 이후 모든 직군 2차 설계와 최종 기획서(GDD)는 이 문서를 기준선으로 삼는다.

## A. 탄약 모델 (오너 확정 — 충돌 A 해소)

- **탄창(매거진)은 무한:** 개별 탄창 수를 세지 않는다. R키로 언제든 재장전 가능.
- **총 탄알(탄약 풀)은 유한 자원:** 탄약이 바닥나면 재장전 불가. "현실의 탄창 수 제한"을 게임에선 "탄창 무한 + 총 탄약 유한"으로 추상화.
- **재장전 시 현재 탄창 잔탄은 탄약 풀로 회수(손실 없음).** 잦은 무손실 재장전 가능하나 총량은 안 줄므로 진짜 압박은 "총 탄약 고갈".
- **현재 탄창 잔탄·총 탄약 모두 미표시.** 소리·체감으로만 추적.
- **탄약 보충:** 적 사살/환경 픽업, 구경별 풀(5.56mm / 9mm / 적 무기 구경).
- ※ 1차의 "전술 재장전 손실 모델"은 **폐기**. 무손실 회수로 확정.

## B. 3대 격발 상태 분리 (오너 확정 — 충돌 B 해소)

| 상태 | 청각 신호 | 의미 | 대응 |
|---|---|---|---|
| 정상 발사 | "탕" (+반동·머즐플래시) | 정상 | 계속 사격 |
| **탄 소진** | **"딸깍" 공이 격발음(소리 O)** + 반동/화염 없음 | 탄창 빔 | **R 재장전** |
| **기능고장(jam)** | **갑자기 안 나감**(딸깍과 구분되는 둔탁/무음) | 무기 고장 | **수동 배제** |

→ 두 "안 나감"이 소리로 구분된다. 오디오 차별화가 시스템 성패의 핵심(테크니컬 최우선 PoC).

## C. HP / 회복 (Director — 충돌 C 해소)

- **2단 체력:** 아머(자동 리젠, 전투 이탈 3s 후) + 생체(자동 회복 없음, 회복아이템/체크포인트만).
- **미표시.** 포스트프로세스(채도저하·혈흔 비네팅·흔들림) + 오디오(심박·이명·호흡) 단계 전달. 중상 시 이동·반동 페널티.
- **평시 긴장 공백 해소:** 긴장축이 ①유한 탄약(미표시) ②재장전 타이밍/노출 ③기능고장 ④HP — **4축**. 잼 단독 의존 문제 해결.

## D. 무기·픽업 (Director — 충돌 D 해소)

- **K-13(주):** 5.56mm 카빈. 신뢰성 높음(잼 저빈도). ※고증: 실제 K13은 카빈/돌격소총, SMG 아님 — "기관단총" 표기 정정.
- **K-5(보조):** 9mm 권총. 즉시 전환(보험), 잼 확률 K-13의 1/3.
- **픽업 무기:** 적 무기. 노후도 높아 잼↑, 탄약은 해당 구경 픽업분만. 상황적 우위 후 소모.

## E. HUD·접근성 (Director)

- 기본 **Pure**(지도/게이지/잔탄 미표시, 디제시스·사운드·화면효과 전달).
- **접근성 토글** 별도(청각장애·색맹 필수): 빈탄창/잼 시각신호, 사운드 시각화, 색맹 모드, 화면효과 강도, 자막. "보는 방식 선택"으로 프레이밍.

## F. 서사·소재 (Director)

- **엔딩:** Bitter(객관적 성공 + 주관적 공허). 신파 금지, 차가움·침묵.
- **소재:** 707/실존 국가 직접 명시는 리스크 → **가상화**(한국군 정서·고증 디테일 유지, 부대·적국·작전은 가공). 세계관 에이전트가 가상 설정 수립.
- **김동수 아크:** "엘리트주의는 안 깨지고 그 대상이 바뀐다".

## G. 핵심 긴장 루프 (확정)

> 정찰(공간 읽기) → 교전 개시 → **유한 탄약을 소리로 추적** → 재장전 타이밍 도박(노출) → (저확률) 기능고장 → 수동 배제 도박 → HP 위험 관리 → 해소(안전구간) → 다음.

네 자원(탄약/시간·노출/무기 신뢰성/HP)이 전부 미표시 상태로 동시 압박. 이것이 게임의 정체성.
