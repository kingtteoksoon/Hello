# 12. 전투·시스템 v2

> **개정(2026-06-25):**
> - **혼합 사격 모델.** 소총(K-13)·권총(K-5)·일반 적무기 = **히트스캔**(반응의 무기). 저격 = **투사체 탄도**(계산의 무기). → 저격소총 **K-14**(7.62×51, 볼트액션) 추가. 탄속 ~800m/s 기준 거리별 낙차·리드가 유의미, 자세별 스웨이(서서100→거치15%)와 호흡 홀드·심박이 명중 안정에 직결. K-14는 **챕터 한정 상황 무기**(능선·고지 OP), 7.62×51은 **완전 별개 극소 풀(15~25발)**·드랍 거의 없음·지정 보급만. 적 AK형의 7.62×39와 풀을 절대 혼동 금지.
> - **탄약 부족 신호 2조건화.** "딸깍"은 두 경우만: **(a) 약실 빔**(현재 탄창 소진, 격발 시 맑은 딸깍 → R) / **(b) 무탄 재장전**(해당 구경 풀 0에서 R 시도 → 장전 실패 헛동작, 둔탁·캐릭터 반응 → 무기 전환). → 플레이어가 가를 상태는 **정상 / (a) / (b) / 기능고장 4가지**. (b)는 약실 잔탄 1발 안전마진 + K-5 전환으로 운사 방지. 1차의 "풀 잔량 점진 딸깍 곡선"은 (a) 빈도 증가라는 자연 부산물로 흡수하고, 공식 신호는 (a)·(b) 둘로 못박음.
> - 아래 본문의 §3·§4(탄약/딸깍)·§7(무기표)은 이 개정으로 갱신됨(K-14 행 추가, 4상태).

> 신 탄약모델(탄창 무한 + 구경별 총탄알 유한 + 무손실 회수 + 전부 미표시) 기반. 모든 수치 **제안값**.

## 1. 핵심 긴장 루프 (4축)
탄창 무한·무손실 회수이므로 "탄창 관리"는 압박이 아니다. 진짜 압박은 **(a) 구경별 풀 고갈** + **(b) 노출 비용("지금 갈 안전한 시간이 있나")**.
```
교전 → "탕"…"딸깍"(탄소진) → [엄폐로 빠져 R? 자주 갈수록 정답이나 R 동안 무방비]
     → 풀이 바닥 가까우면 부분장전→딸깍 빨라짐(=고갈 단서) → K-5(9mm) 전환(잼↑)
     → 적 사살·픽업(픽업 동선=노출 동선) → 다음
```
정서 곡선: 안정(탕)→신호(딸깍)→판단(갈까/빠질까)→회복/악화→다음. 고갈 임박할수록 딸깍 빈도↑ → 체감 위기 자동 상승.

## 2. 사격 모델
- 분산: K-13 ADS 0.6°/힙 3.0°, 발당 블룸 +0.25°, 회복 0.4°/s, 연사 캡 2.2°.
- 반동: 수직 발당 +0.45°(초탄 3발 1.3배), 수평 ±0.15°+드리프트(좌70/우30), 회복 0.18s 지연.
- 연사: K-13 650RPM(2점사 옵션), K-5 세미(~5/s). ADS 전환 K-13 0.25s/K-5 0.18s, ADS 이동 -40%.
- **거치 보정:** 수직 -60%/수평 -70%/분산 -50%, 단 이동 불가+시야 ±35°+진입 0.5s(강력하나 고정 리스크).

## 3. 탄약 시스템 상세
- 규칙: 탄창 무한, **구경별 풀**이 진짜 자원. 풀 0이면 재장전 불가. 재장전 시 잔탄 전량 풀 회수(무손실 → "자주 갈아라"). 전부 미표시.
- 의사 로직: `needed=MAG_CAP-current; draw=min(needed,pool); pool-=draw; current+=draw`. 풀<MAG이면 부분장전.
- **고갈 단서(미표시):** ①재장전 모션/사운드 변화(완전 vs 부분 vs 거의고갈 긁힘음) ②딸깍 빈도 상승 ③거의고갈 경고음+약한 진동 ④(옵션 토글) 캐릭터 보이스.
- 구경별 풀: 5.56(K-13) 240/시작150, 9mm(K-5) 90/45, 적 7.62 별도 60/픽업전용. **독립 풀** → 전환이 전략.
- 픽업: 적 사살 드랍 +8~15(70%), 정예 +20~30. 상자 5.56+40/9mm+25. 상한 초과분 버림. **드랍=교전 중심 생성(픽업=노출)**, 채집 0.4s. 적무기 Condition 40~80%(잼 리스크).

## 4. 빈 탄창("딸깍") vs 기능고장 — 4중 분리
| 구분 | 빈 탄창 | 기능고장 |
|---|---|---|
| 소리 | 맑고 가벼운 "딸깍/틱", 일관 | 둔탁/무음, 거칠고 무거움 |
| 시각 | 노리쇠 후퇴 고정, 화염·반동 없음 | 노리쇠 어정쩡/탄피 걸림 |
| 햅틱 | 짧고 또렷한 단발 | 무겁고 둔함 또는 부재(엇박) |
| 행동 | **R 재장전** | **수동 배제** |
| 빈도 | 자주(정상) | 드묾(패닉 유도) |
소리가 총성에 묻힐 수 있어 시각+햅틱 백업. 튜토리얼서 두 소리 대비 학습.

## 5. 기능고장 시스템
- **확률:** `P_jam = base × (1 + (100-Condition)/100 × k)`, **k=2 권장**(밸런스팀 검증: k=3은 K-5/픽업이 3~4스택만에 캡→불공정). base K-13 0.4%/K-5 1.2%/적 2~4%. **실효 캡 12%**(15%는 6발 1잼=불공정).
- **잼 3종:** 불발 50%(Tap, 0.6s) / 걸림 35%(Tap-Rack, 1.1s) / 이중급탄 15%(Hold-clear, 1.8s). K-5는 걸림/심각 비중↑.
- **입력:** R과 구분되는 별도 배제키. 오입력 시 시간 손해.
- **안전장치:** 연속잼 쿨다운 1.5s(스택 감쇠 −1/1.5s), 캡 12%, 챕터 첫 교전 잼 0% 보호. 복구 중 사격만 불가(이동·시야 유지). 잼 직전 0.3s 시각 단서 의무.

## 6. HP·생존
- 2단: 아머100(자동 리젠, 피격 3s 후 25/s) + 생체100(자동 회복 없음, 의료품 2.5s/체크포인트). 피해 아머→생체 순.
- 4단계 화면효과: 아머손상(청백 플래시·금속음) / 생체피해(붉은 비네팅·심박) / 생체50%↓(채도저하·거친 호흡) / 위독25%↓(적색·흑백·이명·이동/ADS 페널티).
- **즉사 금지:** 풀HP(아머+생체) 기준 최소 2회 피격 생존(적 1탄 데미지 캡, 정예 ≤18).

## 8. 이동 8종 전투 의미
걷기(소음↓·픽업동선) / 달리기(노출 통과, ADS 불가) / 앉기(분산↓·리젠 대기) / 포복(최저 피탄·거치 최적) / 슬라이딩(엄폐 진입 가속) / 린(노출 최소 사격) / 점프·볼트(동선 단축) / 회피 대시(잼·재장전 중 긴급 이탈). 핵심: 이동=대부분 "안전하게 갈/주울/치료할 시간을 만드는" 도구.
