# 02. 레벨 디자인 직군 의견서

## 1. 이 기획이 레벨 디자인에 주는 기회와 제약

**기회**
- HUD가 비었으므로 **레벨 공간 자체가 UI를 대신한다.** 길안내·위협표시·자원관리 정보를 전부 환경에 녹여야 하며, 레벨 디자이너의 권한과 책임이 비정상적으로 커진다. 잘 만들면 핵심 차별점.
- 미니맵이 없으니 플레이어 시선이 항상 월드를 향한다. 환경 스토리텔링·라이팅·실루엣 연출의 투자 대비 효과 극대화.
- 선형 + 무한 재장전이라 자원 페이싱이 단순해져, 여력을 **공간 가독성**에 집중 투입 가능.

**제약**
- "탄창 소진 무알림"은 소리·반동·머즐플래시 부재 같은 디제틱 신호로만 잔탄 추론 → 저위협 학습 공간 필수.
- HP 미표시 + 추가 생존 메카닉 없음 → 회복/후퇴를 유도하는 **공간 리듬(교전 후 안전구간)** 필수. 아니면 "언제 죽는지 모르는" 불공정함.
- Bitter Ending + 선형 = 백트래킹 동기 약함 → **첫 노출에 의미 다 전달**(원테이크 연출 원칙).
- 마커가 없으니 막다른 길 헤맴이 곧 스트레스로 전환.

## 2. 미니맵·마커 없는 내비게이션 — 비(非)HUD 길안내

원칙: **"목표(끌개)는 라이팅·실루엣으로, 즉각적 다음 발걸음은 건축 어포던스로, 막다른 길은 닫힌 신호로"** 3층 구조.

- **조명(가장 강한 끌개):** 진행 방향에 한 단계 밝은 광원/온도 대비. 막다른 길은 어둡고 차갑게, 진행로는 따뜻하게. 깜빡임·화염·조명탄으로 동적 시선 유도.
- **랜드마크·스카이라인:** 레벨 전체에서 보이는 거대 구조물(무너진 관제탑·좌초 선박·송전탑)을 목표 방향 고정. 챕터마다 1개의 강한 실루엣.
- **소리(디제틱 오디오 내비):** 목표 방향 교전음·무전·헬기 로터음. 막힌 방향은 정적. NPC 무전 디제틱 지시.
- **건축·라인 오브 액션:** 복도·난간·파이프·핏자국이 시선을 진행 방향으로. **문 열림=진행로, 닫힘=비진행로** 규칙을 Ch.1에서 확립 후 끝까지 유지.
- **소품 어포던스:** 넘을 엄폐물·기어갈 틈은 고유 시각 언어(닳은 자국·빛 새는 구멍). 어포던스 키트를 Ch.1에 전부 소개.
- **NPC·동료:** 707 분대원의 핸드시그널/무전 소프트 가이드(보조 신호로만, 유일 의존 금지). 적 등장 방향=보통 진행 방향.
- **환경 변화의 일방향성:** 지나온 길 붕괴·화재·잠금으로 물리적 백트래킹 차단.
- **부정 신호:** 잔해·무너진 천장·잠긴 문(손잡이 흔들림)·철조망으로 "여기 아님" 즉시 읽힘.

## 3. 전투 공간 설계 원칙

- **페이싱:** 긴장(좁은 진입)→교전(아레나)→해소(안전 전환구간, HP 비표시 보정용). 아레나 직전 **사전 관찰 지점(vista)**로 적 배치·엄폐물 무의식 학습 → 마커 대체.
- **엄폐 배치:** 저(앉기)·중(거치)·고(완전엄폐) 3종 혼합, 끊기지 않는 엄폐 사슬. 방향성 있게 배치(전진 보상). 파괴/영구 엄폐 시각 구분.
- **적 진입로:** 2개 이상 위협 벡터, 단 메인은 정면·보조는 소리/실루엣 예고. 화면 밖 순간생성 금지, 보이는 진입구에서만.
- **거치 포인트:** 중거리 아레나 진입부 난간/창틀 배치 → 거치=강력하지만 고정 리스크 트레이드오프.
- **고저차:** 적의 상방 위협은 그림자·낙하물·총구화염으로 강하게 예고.

## 4. 이동 메카닉별 전용 공간

- **슬라이딩:** 무너지는 복도·낮은 차단봉 아래 통과 후 엄폐 연결. 노출 구간 빠른 횡단.
- **포복:** 잔해 아래·배수관·철조망 밑. 잠입 시 적 시야선 아래. 거치 결합 매복 저격.
- **점프:** 환경 점프는 명확한 착지 어포던스. 컨테이너 위 일시 고지(노출 리스크).
- **거치:** 창문 거치 농성 구간(측후방 돌입 페널티).

각 메카닉은 Ch.1 저위협 전용 학습 공간 1개 후 후반 복합 응용(누적 설계).

## 5. 선형성과 자율감 양립

- **좁은 갈래:** 메인 양옆 2~3초 갈래(탄약/픽업/환경 스토리), 메인 합류.
- **전술적 우회로:** 정면 vs 측면 잠입 vs 상방 — 목적지 같되 접근법 선택.
- **루프 백 보상:** 돌아 나올 때 새 시야각·지름길.
- **위장된 선형:** 넓은 공간 + 라이팅·랜드마크로 소프트 가이드.
- **속도의 자유:** 강제 스크립트 최소화, "언제 어떻게"의 자유.
- 주의: 갈래는 항상 막다른 길 신호로 닫고, 메인은 열린 신호로 구분.

## 6. 리스크 / 열린 질문

**리스크:** 길 잃음=컨셉 붕괴(헤맴 히트맵 측정, 15초 정체 시 동적 백업 가이드 고려), 잔탄/HP 비표시 불공정, 원테이크 부담(전투 전후 감상 구간), 상방·측방 비가시성, 어포던스 8종 학습 실패.

**열린 질문:**
1. 잔탄 추론 디제틱 신호 강도 합의 (머즐플래시 부재/노리쇠 후퇴 허용?)
2. 동료 NPC를 내비 보조로 공식 채택? (AI 안정성 예산)
3. 체크포인트 밀도 (아레나당 1개+진입 직전 자동저장 제안, Bitter 톤과 상충?)
4. 백트래킹 차단을 물리적 붕괴 vs 보이지 않는 벽?
5. 챕터당 랜드마크/색온도 아트 가이드라인 공식화? (아트팀 규약)
