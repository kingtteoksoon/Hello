# 13. 레벨·미션 디자인 (실제 한반도 7챕터)

> **개정(2026-06-25):** 캐릭터 개정 반영 — **하 일병 삭제, 신임 서지원 소위로 대체**(전원 간부). 콜사인 Alpha. **저격 전용 공간 추가**(능선 침투·고지 OP 등 400m+ 사선, 거치 지점·포복 접근로); K-14 지급/회수 지점과 7.62×51 보급은 해당 챕터 내에만 배치(챕터 밖 회수). 스코프 가시 거리 ≥ 탄도 거리 컬링/콜리전 LOD(보이는데 안 맞는 버그 방지). **엔딩 병목** — 한 명만 데려갈 수 있는 단일 지점을 어디에 둘지 + 두고 갈 인물(라이터 권장: 서지원 살리고 **민 중사**를 둠)을 시나리오와 확정 협의.

> 「소실점」. 선형 싱글 캠페인. 입력: 세계관 8로케이션·시나리오 7챕터·전투(픽업=노출·풀 고갈·거치 트레이드오프·아머 리젠·잼=과부하).

## 1. 레벨 설계 원칙
공간 = UI. 마커가 없으니 공간이 길을 말하고, 탄약 미표시이니 공간이 잔량 게이지를 대신한다.
- **무마커 3층:** L1 매크로(멀리 보이는 단 하나의 랜드마크, 시선 75% 지점, 동시 2개 금지) / L2 메조(통과 가능·불가의 건축 대비) / L3 마이크로(3~5m 단위: 핏자국·탄피·동료의 등, 교전 아레나 출구에 집중).
- **자원의 공간화:** 픽업 밀도로 페이스 전달(흔함=써도 됨, 사라짐=불안). 갱도·제방은 밀도 0 수렴. 거치=절약 보상, 난사 유혹 공간=잼 발화 유도.
- **캠페인 몰입:** 컷 없는 연속성(로딩 매스킹), 인게임 카메라만, 승리/실패 UI 금지. 상태 비가역성(무전 잡음·마모 누적·철책 미러링).

## 2. 무마커 내비게이션 (DMZ 적용)
조명(따뜻=목표, 차가움=경로, 적색=위험: 중계소 적색 항공장애등, GOP 서치라이트), 실루엣(송전철탑·안테나·교각), 소리(한탄강 물소리·바람·무전 패닝·포성), 건축(이중철책·지뢰표지·논두렁·교통호), 동료(민 중사 방향 지시·서지원 소위 오답 차단). **한 공간 2채널 중첩**(접근성). DMZ 철책·표지는 실제로 길을 막으므로 고증과 내비가 합치 — 강점.

## 4. 전투 페이싱 곡선
단위 4박자: 긴장(정찰·거치 관찰)→교전(엄폐 이동·픽업 생성)→해소(전진)→회복창(교전 간격=아머 리젠+픽업). 안전 포켓을 아레나마다 1개 보장(⑤⑥은 희박, ⑦은 사라짐).
**3개 정점:** CH4 잼 첫 충격 → CH5 고갈·잼 최고점 → CH6 무력감 고원. CH7은 의도적 하강 후 딸깍으로 0 수렴. 딸깍/잼 발화는 상승 구간에만(긴장 찰 때 배신).

## 5. 이동 8종 매핑
전용 학습 → 응용: 질주(CH6 전용/②⑦) 슬라이드(CH1/③④⑥⑦) 포복(CH2/①⑤⑥⑦) 마운트(CH3/②④⑦) 클라이밍(CH1/④⑦) 도약(CH2/③⑥⑦) 수영·도섭(CH3/①⑤⑦) 근접(CH1/④⑤). CH7에서 8종 회수=여정 종합.

## 6. 탄약 경제와 공간
픽업=노출(드랍을 교전 직후 위험 위치, 다음 교전 중심에). 풀 고갈 공간화(밀도 단조 감소). 구경 압박: CH4 9mm(CQB 의존+풀 조임+잼) / CH5~6 5.56 고갈→적 7.62 픽업 릴레이(반동·소리 이질감). 잼 직전 난사 유혹 공간 배치(자업자득 체감), 거치=절약 보상.

## 7. 라이트모티프·미러링
철책(②진입선 ★A → ⑦갇힘선, 동일 앵글·재질·소리), 다리(③원경 실루엣 → ⑦무너진 다리, 닿음=좌절), 안개(①보호막 → ⑥⑦수의로 의미 반전), 무전(①클리어 → ⑤무응답 → ⑦침묵). 엔딩 마지막 프레임: 안개 잠긴 끊긴 다리+무전 침묵+딸깍 잔향 동시 수렴.

## 8. 리스크 / 질문
리스크: 무력감↔조작감 붕괴(⑤⑥, 완화: 픽업은 항상 도달가능선 보장, "나쁜 선택지들"로 압박), 무마커+미표시 이중 인지부하, 적무기 픽업 정치·고증 민감(무기 외형 일반화), 엔딩 안티-카타르시스 오인(의도된 정적임을 디제틱으로 명확히).
질문: 이동 8종 정의·입력 확정, 잼 발화 정량 임계, 적무기 구경/반동 스펙, 아머 리젠 발동 조건, CH5 대면 분량, CH7 진실 전달 매체, 하 일병 운명, 8로케이션 지리 인접성·실지명 허구화 수위.
