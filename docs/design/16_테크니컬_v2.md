# 16. 테크니컬 v2 (UE5)

> **개정(2026-06-25):**
> - **혼합 사격 구현.** 무기 PDA에 `EFireSolution{Hitscan,Projectile}` 플래그. K-13/K-5/적무기=`LineTrace`. 저격 K-14=**투사체**: 권장 구현은 **커스텀 서브스텝 적분**(`v+=g*dt; pos+=v*dt`, 구간별 트레이스 → 터널링 원천 차단; 동시 비행 1~3발이라 성능 부담 낮음). PMC+CCD는 폴백. 잼/딸깍 판정은 사격모델과 무관하게 공통 선평가 후 ③정상에서만 히트스캔/투사체 분기 → 저격도 잼 시스템에 자연 편입.
> - **조준 안정 = 단일 `AimStability[0..1]`** 하나로 통합해 카메라 sway 진폭과 발사 오차각에 동시 곱(보는 흔들림=실제 명중 일치). 입력: 거치(GameplayTag `State.Mounted`)·자세·호흡 홀드(Enhanced Input Hold, `IMC_Scoped/Mounted` 한정)·심박(기존 HP 4단계 소스 재사용). 볼트액션은 FSM `Cycling` 강제 경유.
> - **탄약 4상태**(정상/(a)약실빔/(b)무탄재장전/잼)를 상태 추가가 아닌 **전이 이벤트**로 노출. (b)는 무손실 회수 의사로직에 `drawn==0` 가드 한 줄만 추가해 정합(회수 로직 불변). MetaSounds `SignalState` 파라미터로 4종 변별 — **M0 블라인드 테스트를 3종→4종으로 확장**((a) vs (b) 혼동 방지가 최우선).

> 고지: Motion Matching/StateTree/MetaSounds/CMC 확장 성숙도는 엔진 마이너 버전(5.3~5.6+)마다 다름 — 착수 버전으로 Production-Ready 재확인 + 버전 동결 정책 필요. **캠페인 싱글(멀티 없음)** 전제.

## 1. 아키텍처
- **GAS 전면 채택 비권장**(멀티 전용 비용 순손실). 권장 **(A) GAS 없이 GameplayTags 플러그인만**(무기/잼/이동 상태 태그화, 회복/리젠/억압은 타이머 기반 `UStatusEffectComponent`) — MVP 적합. 상태효과 5종 이상이면 **(B) GAS 부분**(ASC를 플레이어/주요 AI에만, Attribute+GameplayEffect만, 리플리케이션 끔). **GameplayTag는 처음부터 도입.**
- **Enhanced Input:** 상태별 IMC 스택(Default/Mounted/Prone/Vaulting/Cinematic, priority 레이어링). 잼 복구=Hold 트리거(빠른 재장전과 구분), 수동 노리쇠=Tap. IMC 교체는 FSM이 주도(단방향).
- **데이터 주도:** 무기 정의=`UPrimaryDataAsset`+AssetManager(에셋 레퍼런스 많음), 밸런싱 수치=`DataTable`(디자이너 튜닝). 구경=GameplayTag(`Ammo.Caliber.762x39`).

## 2. 무기·탄약 구현
- **무기 FSM:** enum/GameplayTag 경량 FSM을 `UWeaponComponent`에 C++. `Idle→Firing→(Cycling)→Idle` + `Empty`/`Malfunction`/`Reloading`/`ManualClearing`. 발사 트리거 시 ①약실 비었나(딸깍) ②잼 롤 ③정상 순 평가. 애님 몽타주 `AnimNotify`로 게임플레이/사운드 동기.
- **구경별 풀+무손실 회수 의사로직:**
```
AmmoPool: Map<CaliberTag,int>  // 진짜 자원
LoadedCount, MAG_CAP (둘 다 미표시)
재장전: needed=MAG_CAP-LoadedCount; drawn=min(needed,AmmoPool[cal]); LoadedCount+=drawn; AmmoPool[cal]-=drawn
발사: LoadedCount-- ; ==0이면 다음 격발=딸깍
```
탄창 객체 추적 없이 수치 풀로만 관리(빈/반탄창 인스턴스 불필요). 전부 미표시(디버그 빌드만 CVar 오버레이).
- **픽업:** `AWeaponPickupActor`↔`UInteractionComponent`. 잔탄·**Condition 승계**(주운 적무기 Condition↓→잼↑), 구경 풀 합류. 드랍 시 상태 직렬화(회수 가능=무손실 일관).

## 3. 기능고장 구현
- `Condition[0..1]` 런타임 인스턴스 데이터. 연사·환경·출신·정비로 변동.
- **per-shot 확률 롤:** `P_jam = Base × ConditionCurve(Condition) × CaliberFactor × HeatFactor`. ConditionCurve=`UCurveFloat`(비선형, 디자이너), 롤=`FRandomStream`(재현 가능 — 스크립트 잼/QA).
- 잼 3종: 불발(Tap-Rack)/걸림(Hold)/이중급탄(다단계 Hold), 전용 몽타주+잠금(`IMC_Malfunction`). MVP=단일 "정비" 버튼(컨텍스트 자동 몽타주), 하드코어=종류별 입력.
- 안전장치: 연속잼 쿨다운(복구 후 N초 P=0), 확률 캡 클램프, 첫교전 보호(`State.Combat.GracePeriod` 태그), pity 보정 옵션. 파라미터는 난이도별 DataTable.

## 4. 비-HUD 피드백 기술 (최우선 PoC)
- **격발 3상태 오디오 = MetaSounds 우선 PoC(M0 마일스톤):** 정상(풀 임팩트)/탄소진(맑고 가벼운 딸깍, 하이엔드)/잼(둔탁·무음 가까움, 로우엔드). MetaSound 입력 파라미터로 Condition·잼종류 질감 연속 변조. **블라인드 테스트: 세 소리만으로 HUD 없이 100% 구분 가능해야 "전부 미표시" 성립.** (성숙도 고지: 대안 Sound Cue+파라미터.)
- **HP 2단:** `MaterialParameterCollection`(MPC)로 전역 PP 구동. 아머=가장자리 글리치/디지털 노이즈(자동 리젠), 생체=채도저하·비네팅·심박 펄스(수동 회복까지 지속). 2단을 다른 시각 언어로.
- 카메라 셰이크(`UCameraShakeBase`, 정상=리듬/잼=불규칙 덜컹), 햅틱(`UForceFeedbackEffect` 3상태 차별, 키마 부재→보조).

## 5. 이동·컨텍스트
- **CMC `CustomMovementMode` 확장:** 슬라이딩(속도/마찰 커브), 포복(캡슐 리사이즈+제약+IMC), 거치(상태머신+카메라 제약, 반동↓·스윙 각 제한), 엄폐(MVP는 경량 lean, 풀 커버는 리스크). 싱글이라 `FSavedMove` 네트워크 보일러플레이트 생략 가능(이점).
- 컨텍스트 감지: `UInteractionComponent`+트레이스(vault 높이·거치 표면 법선·픽업·엄폐). 동일 버튼 컨텍스트 분기. EQS는 AI용, 플레이어는 직접 트레이스(가볍고 결정적).
- **ABP 우선(MVP), Motion Matching 보류**(대량 모캡·메모리·튜닝 부담, post-MVP 검토). 상체 사격+하체 이동은 Layered/Additive.

## 6. AI
- **StateTree 권장(신규/UE5)** 또는 보수적 대안 **BT+Blackboard**(검증됨). 혼용 지양. 보병=단순, 침투조=동일 트리+파라미터/서브트리 분화.
- **Perception 청각 연동(핵심):** `AISense_Hearing` — 발사 시 `ReportNoiseEvent`(구경별 소음 반경 차등), 슬라이딩/달리기 소음. → 무소음 플레이(K-5 근접·포복)가 전술적 의미.
- 엄폐(EQS 스코어링: 시야 차단+거리), 픽업(무장해제 AI가 주변 무기, 플레이어와 파이프라인 공유), 억압(근탄 피격 시 디버프=조준↓·엄폐 강제).

## 7. 캠페인 파이프라인
- **World Partition 비권장(오픈월드용)** → 전통 **Level Streaming**(LevelStreamingVolume/수동 Load·Unload)+Sublevel(라이팅/지오/AI 분리), 챕터 단위.
- **체크포인트:** `USaveGame` 스냅샷(무기 Condition·풀·진행 플래그·잼 상태 직렬화). 선형이라 단순.
- **스크립트 잼(CH4/CH7):** Level Blueprint/스크립팅 데이터로 트리거 진입 시 `ForceJam(type)` 또는 P_jam↑ — 잼 시스템에 스크립트 훅 노출(드라마적 잼). GameplayTag로 시퀀스 상태.
- **컷신/무전:** `Level Sequencer`(시네마틱), 무전은 경량 Sequencer+MetaSounds+자막(비차단), `IMC_Cinematic`으로 입력 제어.

## 8. MVP·성능·Steam·리스크
- **MVP(수직 슬라이스):** 무기 2종+픽업 1종, 구경 풀·무손실 재장전·**격발 3상태 완성**, 잼 3종+안전장치, **오디오 3상태 PoC를 M0 최우선**, 이동 4~5종(기본+슬라이딩·포복·거치·경량 엄폐), HP 2단 PP+오디오, AI 보병 1종(청각·엄폐·억압), 레벨 1~2 구간(CH4 스크립트 잼 검증). ABP, GAS 미채택+GameplayTag.
- **성능:** PP 머티리얼 다중 패스 누적 관리, MetaSounds 보이스/DSP 프로파일(`Audio Insights`), AI 청각 이벤트 빈도·EQS 비용(`Unreal Insights`), Significance Manager LOD, Level Streaming 히치 방지. 최저 사양 먼저 정의 후 Lumen/Nanite on/off.
- **Steam:** `OnlineSubsystemSteam`(업적·클라우드세이브·통계), Steam Input(리맵·접근성), Shipping+IoStore, 한국어 1차+현지화(StringTable).
- **리스크:** R1[높음] "전부 비표시" UX 검증 실패→M0 오디오 PoC+블라인드 테스트 조기검증, 실패 시 최소 디제틱 백업(약실 점검 동작). R2 엔진 성숙도→보수 대안 병기·버전 동결. R3 잼=짜증 위험. R4 CMC 커스텀 복잡도→단계적. R5 픽업+구경 풀 엣지케이스.
- **질문:** 약실 +1 정책? 적무기 슬롯(대체/임시/추가)? 잼 복구 단일버튼 vs 종류별? Condition 회복 수단? 생체회복 아이템 vs 쿨다운? 엄폐 깊이(lean vs 풀)? 엔진 버전 동결 시점? 최저 사양/Lumen 정책? 난이도 단계 수?
