# 10. 세계관·설정 (실제 한반도)

> 오너 확정: 배경은 **실제 대한민국/한반도**, 적은 **북한**. 부대명만 가상화(707 모티브). 실제 한국군 정서·고증·지리 유지. 캠페인 위주 싱글플레이.

## 1. 프로젝트 가제 후보

| 후보 | 톤/의미 |
|---|---|
| **「소실점 / VANISHING POINT」** ★1순위 | 선형 캠페인의 "한 점으로 수렴" 구조 + "통제의 환상" + Bitter 엔딩을 한 단어로. 글로벌 노출 유리 |
| 「철책선 / IRON LINE」 | 건조·군사적. 분단·DMZ 철책 직접 환기. 정서 마케팅 자산(부제 병기 권장) |
| 「최종 교신 / LAST CALL」 | 끊기는 무전·일회성 작전의 비장함(다소 보편적) |
| 「사선(死線) / DEADHAND」 | 거칠고 직설적, 격발 손맛과 어울림(핵 시스템명 혼동 주의) |

→ **Director 추천: 「소실점 / VANISHING POINT」** (부제로 「철책선」 병기 가능).

## 2. 시대·지정학 (실제 한반도)

- **시점:** 근미래의 "지금"(202X년대 후반). 미래 병기·SF 배제, 현대전 유지(드론·통신감청·정밀유도는 현실 보급 수준).
- **무대:** 정전 70여 년의 한반도. DMZ·접경지역의 긴장이 고조된 "전면전 직전의 회색지대". 전면전이 아니라 **통제 가능하다고 믿어지는 한 건의 작전**이 통제를 벗어나는 이야기로 좁힌다.
- **구도:** 대한민국(국군) vs 북한(조선인민군). 국지 도발(침투·포격·요인 납치)이 반복되는 상황. 강대국 후견은 "동맹국/우방"으로만 간접 지칭(국제 정세 직접 묘사는 절제).

## 3. 진영 설정

**아군 — 대한민국 국군**
- 주인공 부대: **육군 특수전사령부 직할 특임단**, 그중 김동수가 이끄는 **알파팀**(호출부호 **Alpha-01**). 707특임단 모티브이되 명칭은 일반화. **부대원 전원이 간부(장교·부사관)이며 소속·신원이 2급 군사기밀** — 직할 특임대 특성상 병(兵)은 없다. "최강"이라는 자부심이 부대 정체성.
- 김동수 대위 = 알파팀 팀장(콜사인 **Alpha-01**)·중대장. 소령 진급 예정.
- 지원 제대: 정규 보병·포병·의무·통신. 김동수가 "비효율"로 여겨 자주 부딪히는 체계이자, 동시에 그가 끝까지 지키려는 사람들.

**적군 — 북한**
- 조선인민군 정규 보병 + 비대칭 침투제대(특수작전군 계열의 가상 침투조). 인해·포병·기만전·민간지대 은폐 활용. 개개인은 위협적이지 않으나 "끝없이 밀려오고 통제 불가능한 변수가 발생"하는 집단으로 연출 → 유능한 개인을 무력화하는 환경.

**제3의 변수 (회색)**
- 후반, 아군 상부의 정치적 판단·통신 두절·우군 오인사격 등 **"적이 아닌 아군·체계"가 통제 상실의 진짜 원인**으로 드러남 → 김동수의 멸시 대상이 적→체계→자신으로 이동하는 아크 장치.

## 4. 작전 배경 (단일 선형 작전)

**작전명 「소실점」**
- 발단: 북한이 접경 아군 통신중계소를 기습 점거하고 핵심 인사(망명 의사를 밝힌 고위 인물/탈주자) 1인을 비무장지대 인근으로 끌고 들어간다.
- 임무: 「창」 Lance-1(김동수)이 **단독 침투 → 인질 위치 확인 → 구출 → 적 지휘노드 제거 → 탈출**. 표면상 "정밀하고 깔끔한 한 건".
- 반전 구조(선형 한 줄기): ①깔끔한 침투(통제 환상) → ②변수 발생(정보 오류·적 규모 과소평가) → ③구출하지만 가치 붕괴(인질의 진실/작전의 진짜 목적) → ④우군·상부의 무능·배신으로 탈출선 붕괴 → ⑤**Bitter 엔딩**(임무 완수, 그러나 통제한 것은 아무것도 없었음).

## 5. 지역·로케이션 팔레트 (7~8 챕터, 실제 한국 지리)

1. **강원 산악 야간 능선 침투** — 비 오는 야간, 적막·관측·은밀. 거치/포복 학습 무대. 통제감 최고.
2. **GOP/DMZ 이중철책·지뢰지대** — 녹슨 철책·감시초소·지뢰. 좁은 통로, 첫 교전. 분단 정서 핵심 비주얼.
3. **임진강·한탄강 수몰 폐촌** — 댐 방류로 반쯤 잠긴 폐촌. 슬라이딩·수중 포복·시야 차단. 민간의 흔적=전쟁의 공허.
4. **점거된 통신중계소(CQB)** — 실내 근접전. K-5·픽업 강조. 인질 1차 정보.
5. **북한 남침용 땅굴·지하 벙커** — 폐소공포·어둠·**탄약 고갈 압박(딸깍·기능고장 연출 정점)**.
6. **임진강 제방·개활 논(안개)** — 적 포병·인해의 압도. "유능해도 못 막는" 무력감 절정. 엄폐 사슬 이동.
7. **고지 OP 관측소** — 작전의 진실이 무전으로 드러나는 서사 분기점. 거치 저격·관측.
8. **임진강 하구 무너진 다리(피날레)** — 안개 속으로 사라지는 철수로. 통제 상실의 시각적 종착. Bitter 엔딩 무대.

## 6. 톤·테마

- **전쟁관:** 영웅서사 거부. 전장은 "정밀하게 설계해도 한순간 변수로 무너지는 시스템". 플레이어 기량이 높을수록 통제 불가능한 것들의 윤곽이 더 또렷이 보이도록.
- **주제 「모두를 살리려는 자의 비극」:** 김동수의 통제 욕구는 경멸이 아니라 죄책감과 책임에서 나온다(선임의 유언 "살아남아"). 시스템 차원의 불확실성(탄약·HP 미표시, 격발 3상태, 통제 불가능한 기능고장)은 곧 "아무리 계산해도 전부를 살릴 수는 없다"는 그의 한계를 게임플레이로 번역한다. 미표시 정보와 jam은 그가 끝내 통제하지 못하는 변수다.
- **정서 키워드:** 비, 안개, 무전 잡음, 녹슨 철책, 끝나지 않은 정전.

## 7. 고증 디테일 가이드 (실제 한국군)

- **장비:** K-13 카빈(5.56mm, ※카빈/돌격소총 — "기관단총" 표기 정정), K-5 권총(9mm). 적 무기는 AK 계열·PKM류(북한 제식). 픽업 시 탄종·조작감 차이 체감.
- **계급/호칭:** 실제 한국군 호칭·무전 절차어("이상", "수신양호", "통신두절"). 콜사인 Lance-1, Lance-2.
- **교전수칙(ROE):** 정전 회색지대의 발포 권한·민간 식별 긴장을 컷신/무전으로. 후반 ROE 붕괴=통제 상실 신호.
- **부대 문화:** 특임대의 엘리트 자부심, 일반 보병과의 위계, 전우애, 억센 군대 말투.
- **분단 정서:** 철책·지뢰·대북 방송·실향·전단. "휴전 70년", "잊힌 전쟁" 등으로 환기.
- **민감성 절제:** 실제 부대명(707) 직접 표기 회피(→「창 특임대」). 특정 정치 진영·실존 정치인·실제 작전명 직접 묘사 금지. 북한군은 "체제의 말단으로 던져진 인간"으로도 그려 일방적 악마화 회피(QA 권고와 연계).

## 8. 시나리오/레벨 팀 인계 — 설정 훅

- **격발 고장 = 서사 비트:** 가장 중요한 순간(인질 눈앞)에서 "갑자기 안 나감 → 수동 배제" 스크립트.
- **탄약 고갈 압박:** 땅굴/제방에서 의도적 고갈 → 적무기 픽업 강제 → "내 무기조차 내 통제 밖".
- **인질의 진실:** 구출 대상이 "구할 가치가 있었는가"를 흔드는 정보 → 작전 의미 붕괴.
- **우군 무능/배신:** 탈출선(헬기/통신)이 상부 판단·오인사격·통신두절로 붕괴 → 적이 아닌 체계가 적이 됨.
- **김동수 회색지대 압박 3단:** 규정을 어겨서라도 살리는 결단(전반) → 막을 수 없는 손실의 누적(중반) → 모두를 살릴 수 없을 때의 결과중심 비극적 판단(후반). 대사·무전으로 단계 설계.
- **소실점 모티브:** 안개·다리·철수선이 챕터마다 멀리 보였다가 피날레에서 닿지 못하고 사라짐(비주얼 라이트모티프).
- **무전 라이트모티프:** "Alpha-01, 응답하라"가 초반엔 또렷하다 후반엔 잡음에 묻히고, 마지막엔 무응답.
- **철책 미러링:** 2챕터의 철책을 "막는 선"으로 진입, 피날레에서 같은 류의 철책을 "갇히는 선"으로 재방문.
